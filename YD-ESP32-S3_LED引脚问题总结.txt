=====================================================
一、问题描述
=====================================================

在为 YD-ESP32-S3 开发板编写 RGB 呼吸灯程序时，最初使用了普通 PWM
引脚控制方式（GPIO 18/19/20），但烧录后 LED 没有反应。

=====================================================
二、问题原因分析
=====================================================

YD-ESP32-S3 开发板的板载 RGB LED 并非普通的三通道 RGB LED（分别
连接三个 GPIO 引脚），而是采用 **WS2812 单总线 RGB LED**。

关键区别：

| 类型 | 控制方式 | 引脚数量 | 驱动方式 |
|------|---------|---------|---------|
| 普通 RGB LED | 三路 PWM | 3个 | analogWrite() |
| WS2812 RGB LED | 单总线 | 1个 | 特殊时序协议 |

WS2812 LED 使用专用的通信协议，需要精确的时序控制，不能用普通的
analogWrite() 或 digitalWrite() 来控制。

=====================================================
三、正确的引脚信息
=====================================================

根据开发板资料中的 MicroPython 例程（main.py）：

板载 LED 类型：WS2812 RGB LED（单颗）
连接引脚：GPIO 48
通信协议：WS2812 单总线协议（800kHz）
颜色顺序：GRB（Green-Red-Blue）

代码证据（来自资料中的例程/main.py）：
```python
from machine import Pin
from neopixel import NeoPixel
pin = Pin(48, Pin.OUT)   # set GPIO48 to output to drive NeoPixels
np = NeoPixel(pin, 1)    # create NeoPixel driver on GPIO48 for 1 pixel
np[0] = (100, 0, 0)      # set the first pixel to red
np.write()               # write data to all pixels
```

=====================================================
四、解决方案
=====================================================

方案1：使用 Adafruit_NeoPixel 库（推荐）

优点：简单易用，社区支持好，功能丰富
缺点：需要安装外部库

步骤：
1. 在 Arduino IDE 中打开"工具 > 库管理器"
2. 搜索"Adafruit NeoPixel"并安装
3. 使用以下代码控制：

```cpp
#include <Adafruit_NeoPixel.h>

#define LED_PIN    48
#define LED_COUNT  1

Adafruit_NeoPixel pixels(LED_COUNT, LED_PIN, NEO_GRB + NEO_KHZ800);

void setup() {
  pixels.begin();
  pixels.setBrightness(255);
}

void loop() {
  pixels.setPixelColor(0, pixels.Color(255, 0, 0));  // 红色
  pixels.show();
  delay(1000);
  
  pixels.setPixelColor(0, pixels.Color(0, 255, 0));  // 绿色
  pixels.show();
  delay(1000);
  
  pixels.setPixelColor(0, pixels.Color(0, 0, 255));  // 蓝色
  pixels.show();
  delay(1000);
}
```

方案2：使用 ESP32 内置 RMT 外设（无需外部库）

优点：不需要安装任何库，直接使用硬件驱动
缺点：代码较复杂

步骤：直接使用 ESP-IDF 的 RMT API 或 Arduino 的 ledcWrite() 模拟

方案3：使用 ESP32 LEDC PWM 模拟（简单版，无需库）

优点：代码简单，不需要外部库
缺点：精度较低，可能出现颜色失真

=====================================================
五、错误的做法（请勿使用）
=====================================================

错误代码示例：
```cpp
// ❌ 错误！WS2812 LED 不能用普通 PWM 控制
#define RED_PIN    18
#define GREEN_PIN  19
#define BLUE_PIN   20

void setup() {
  pinMode(RED_PIN, OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
  pinMode(BLUE_PIN, OUTPUT);
}

void loop() {
  analogWrite(RED_PIN, 255);  // ❌ 无效操作
  delay(500);
}
```

原因：YD-ESP32-S3 没有将 GPIO 18/19/20 连接到板载 RGB LED，
这些引脚是引出到排针上的。

=====================================================
六、开发板上的其他 LED
=====================================================

除了板载 WS2812 RGB LED（GPIO 48），YD-ESP32-S3 还有：

1. 电源指示灯（Power LED）
   - 颜色：红色
   - 位置：靠近电源接口
   - 功能：指示电源是否接通
   - 不可编程控制

2. 状态指示灯（可能有，取决于具体版本）
   - 颜色：绿色或蓝色
   - 引脚：GPIO 12（参考例程/blink-input.py）
   - 功能：可通过程序控制

示例代码（GPIO 12）：
```cpp
#define STATUS_LED_PIN 12

void setup() {
  pinMode(STATUS_LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(STATUS_LED_PIN, HIGH);
  delay(500);
  digitalWrite(STATUS_LED_PIN, LOW);
  delay(500);
}
```

=====================================================
七、总结
=====================================================

1. YD-ESP32-S3 板载 RGB LED 是 WS2812 类型，必须使用专用驱动
2. WS2812 LED 连接在 GPIO 48，需要使用 Adafruit_NeoPixel 库或 RMT API
3. GPIO 18/19/20 是引出到排针的通用引脚，没有连接到板载 RGB LED
4. GPIO 12 可用于控制状态指示灯（如果焊接了）
5. 电源指示灯（红色）不可编程控制，仅指示电源状态

正确的 LED 控制流程：
1. 确认 LED 类型（WS2812 vs 普通 RGB）
2. 使用对应的驱动方式
3. 使用正确的引脚号（GPIO 48）
