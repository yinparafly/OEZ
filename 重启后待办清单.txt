三、Hyper-V 离线安装指南
================================================================

方法 A: 使用 Windows 功能对话框 (推荐)
  1. 按 Windows + R → 输入 optionalfeatures → 回车
  2. 找到 "Hyper-V" → 展开
  3. 勾选 "Hyper-V 管理工具" + "Hyper-V 平台"
  4. 点确定 → 重启电脑
  5. 重启后验证: PowerShell 中运行 Import-Module Hyper-V

方法 B: DISM 离线安装
  如果方法 A 不行，尝试:
  1. 找到 Windows 10/11 安装 ISO 或 U盘
  2. 挂载 ISO，记住盘符 (假设是 D:)
  3. 以管理员运行:
     dism /online /enable-feature /featurename:Microsoft-Hyper-V-Tools-All /all /source:D:\sources\install.wim

方法 C: 下载离线包
  从 Microsoft 官网下载 Windows 10/11 评估版 ISO
  挂载后用 DISM 安装
