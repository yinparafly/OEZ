# STM32F103 ABZ磁编码器数据记录仪 — 设计方案

## 一、项目概述

基于STM32F103C8T6核心板，读取AS5047P磁编码器的ABZ增量信号，实现弹射过程的转速数据记录。

### 1.1 核心需求

| 需求 | 说明 |
|------|------|
| 编码器 | AS5047P，ABZ增量输出模式，出厂默认1000 PPR（4000步/转） |
| 采样率 | 4kHz（TIM3定时中断） |
| 触发条件 | 转速 > 10 RPM（迟滞12/8） 且 Z信号出现一次 |
| 记录范围 | 触发前200点（50ms）+ 触发后0.8秒（3200点）= 3400点 |
| 数据内容 | 仅编码器计数值（uint32_t），转速和时间戳在PC端推算 |
| 环形缓冲 | 3584点 × 4字节 = 14KB |
| 存储介质 | SD卡（SPI模式 + FatFS），8GB FAT32 |
| 启动方式 | UART串口指令（当前）+ GPIO电平（将来扩展） |

### 1.2 应用场景

弹射器从0 RPM急速加速至~5000 RPM，系统持续监控，满足触发条件后记录弹射过程的编码器数据。

## 二、硬件设计

### 2.1 核心器件

- **MCU:** STM32F103C8T6（Cortex-M3, 72MHz, 64KB Flash, 20KB RAM）
- **编码器:** AS5047P磁编码器（ABZ增量输出模式，出厂默认1000 PPR）
- **SD卡:** 8GB microSD（FAT32格式，SPI模式）

│  │  读TIM2->CNT  │ →  │  上次差值  │ →  │  写环形缓冲   │    │
│  │  (当前计数值) │    │  (窗口RPM) │    │  (3584点)    │    │

│                                                             │
│  Z相EXTI0中断（PB0）：z_flag = true                         │

                              ↓

### 4.3 定时器配置

#### TIM2 — 编码器模式（AB相计数）

| 参数 | 值 | 说明 |
|------|-----|------|
| 预分频 | 0 | 不分频，直接计数边沿 |
| 自动重载 | 0xFFFFFFFF | 32位最大值，防溢出 |
| 编码器模式 | TI1+TI2 | 4倍频（每转4000个计数） |
| 计数方向 | 自动 | 硬件判断正反转 |

#### TIM3 — 4kHz采样定时器

| 参数 | 值 | 说明 |
|------|-----|------|
| 时钟源 | APB1 = 36MHz | TIM3挂在APB1上 |
| 预分频 | 0 | 不分频 |
| 自动重载 | 9000 - 1 | 36MHz / 9000 = 4000Hz |
| 中断 | 使能 | 每次更新触发IRQ |

#### EXTI0 — Z信号中断

| 参数 | 值 |
|------|-----|
| 引脚 | PB0 |
| 触发方式 | 上升沿 |
| 中断优先级 | 最高（高于TIM3） |

### 4.4 SPI配置（SD卡）

| 参数 | 值 |
|------|-----|
| SPI | SPI1 |
| 模式 | 主机，全双工 |
| 速率 | 分频后 ~18MHz（APB2=72MHz / 4） |
| CPOL | 0 |
| CPHA | 0 |
| NSS | 软件控制 |
| 数据位 | 8bit |

### 4.5 IWDG独立看门狗

| 参数 | 值 |

## 五、数据记录格式

### 5.1 文件名命名

```
CAT_00001.CSV
CAT_00002.CSV
...
```

文件计数器存储在SD卡 `INDEX.TXT` 中，每次写卡完成后更新。避免Flash磨损。

### 5.2 CSV格式

```csv
index,count
0,12345
1,12348
2,12352
...
3399,87654
# CHECKSUM: A3B2C1D0
```

- `index`: 数据点序号（0~3399）
- `count`: TIM2->CNT计数值（uint32_t）
- 末行 `CHECKSUM`: 所有count值的CRC32校验和

### 5.3 PC端推算

PC读取CSV后推算：
- **RPM:** 相邻count差分 / 采样间隔(0.25ms) / 4000步/转 × 60
- **时间戳:** index × 0.25ms + 记录起始绝对时间

## 六、触发逻辑详解

### 6.1 流程

1. 系统上电 → IDLE状态，等待启动指令
2. 收到'G'（或GPIO启动） → MONITOR状态
3. 4kHz中断持续读TIM2->CNT → 写入环形缓冲
4. 在主循环中每100ms计算一次窗口RPM：
   - 取当前count与100ms前的count差值
   - RPM = Δcount / (100ms × 4000步/转) × 60
5. RPM迟滞比较：
   - RPM > 12 → 设置 `rpm_ok = true`
   - RPM < 8  → 清除 `rpm_ok`
6. Z中断设置 `z_flag = true`
7. 当 `rpm_ok && z_flag` 同时满足 → TRIGGERED状态
   - 记录 `trigger_index = head`（缓冲中当前写入位置）
8. 等待0.8秒后进入WRITING状态
9. 禁TIM3中断 → 从缓冲提取3400点到临时数组 → 恢复TIM3中断 → SPI+FatFS写入SD卡CSV
10. 写入完成 → 回到MONITOR状态

### 6.2 环形缓冲读取（触发后）

```
trigger位置 = head（触发时刻的写指针）
前200点起始 = (head - 200) & 0xDFF    // 3584-1 = 0xDFF
后3200点结束 = (head + 3200 - 1) & 0xDFF
总共3400点 = 200 + 3200
```

## 七、关键注意事项

### 7.1 中断与主循环互斥

- 4kHz中断写入缓冲区（只修改head指针）
- 主循环在SD卡写入前**只禁TIM3中断**（`TIM_ITConfig(TIM3, TIM_IT_Update, DISABLE)`），开TIM2和EXTI0继续正常工作
  - TIM2编码器硬件计数不受影响
  - Z中断仍能响应（但z_flag不会被消费）
- 一次性读取3400点到临时数组后恢复TIM3中断
- 禁中断时间：微秒级，不影响4kHz时序

### 7.2 SD卡写入性能

- FatFS + SPI模式下，单次写入13.6KB数据
- SPI模式实测~200KB/s，单次写入约70ms
- 写入期间丢失的采样点（约280个）发生在写入完成后，不影响已记录的数据
- 文件末尾写入CRC32校验和，PC端可验证数据完整性

### 7.3 滚动RPM计算

不在4kHz中断内做浮点运算，改为在主循环中用**定时窗口法**：
- 每100ms采样一次 `count` 和 `time`
- RPM = (Δcount / 4000) / (Δt_sec) × 60
- 使用整数运算 + 迟滞比较避免边界抖动

### 7.4 编码器溢出处理

- TIM2为32位计数器，最大值4,294,967,295
- 在9000 RPM × 4000步/转 = 600,000 步/秒下
- 约7150秒（~2小时）才溢出，单次弹射仅~秒级，无需处理溢出

### 7.5 Z信号时序

- 在10RPM时，Z信号间隔 = 60/10 = 6秒
- 弹射从0→5000 RPM过程中，第一个Z信号出现在第一圈完成后
- 触发逻辑需要在弹射开始后等待第一个Z，延迟约数毫秒到数秒（取决于初始加速度）

## 八、LED状态指示

| 状态 | LED行为 |
|------|---------|

## 十、构建与烧录

### 10.1 工具链

- **编译器:** ARM GCC 13.2.1（`D:\arm-gcc\xpack-arm-none-eabi-gcc-13.2.1-1.1\bin`）
- **烧录:** ST-Link Server + ST-LINK_CLI

### 10.2 Makefile构建

```makefile
TARGET = project
CC = arm-none-eabi-gcc
OBJCOPY = arm-none-eabi-objcopy
CFLAGS = -mcpu=cortex-m3 -mthumb -DSTM32F10X_MD -DUSE_STDPERIPH_DRIVER
LDFLAGS = -Tlinker.ld --specs=nano.specs -Wl,--gc-sections

all: $(TARGET).hex

$(TARGET).hex: $(TARGET).elf
    $(OBJCOPY) -O ihex $< $@

clean:
    rm -f *.o *.elf *.hex
```

### 10.3 ST-Link烧录

```
ST-LINK_CLI.exe -c SWD -p project.hex -Rst
```
