# 工作要求（电机测试规则）

应用对象：ab i_monitor_h743 固件开发/调试过程中对真实电机的所有启停操作（手动或命令行触发）。

## 强制规则

1. **测试几秒就停机**：任何自动化/手动测试，电机连续运转时间不得超过 5 秒；测试完成后立即发 `PWM 0` 停机。
2. **禁止长时间空转**：不允许电机持续（>30 秒）运转；长测必须分段进行，段间停机冷却。
3. **默认低速优先**：不需要高速运转时，PWM 占空比以 **2000 转/分（rpm）** 为上限，每步 PWM 增量不大于 100‰，避免突然全速。
4. **先接电源后转**：给电机供电前确认 PWM 命令为 0（或未发送任何 PWM 命令）。
5. **异常立即停机**：转速异常、异响、抖动、计数异常时第一时间发 `PWM 0` 断电。

## 自动化脚本要求

- 自动化控制脚本（如 PC 端自测脚本）必须内置**看门狗停机**：任何路径执行完毕后必发 `PWM 0`；
  脚本异常退出（异常/中断）时也必须在 `finally` 中发 `PWM 0`。
- 脚本每次运行开始时默认发送 `PWM 0` 复位占空比，再按需提速。
