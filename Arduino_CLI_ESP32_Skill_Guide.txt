```powershell
$env:ARDUINO_DATA_DIR = "D:\Arduino\Arduino15"
```

=====================================================
三、常用命令
=====================================================

3.1 编译命令

```powershell
$env:ARDUINO_DATA_DIR = "D:\Arduino\Arduino15"
"D:\Program Files\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe" `
  compile --fqbn esp32:esp32:yd_esp32s3_n8r2 "D:\servotest\YourProject" `
  --config-file "C:\Users\tt\.arduinoIDE\arduino-cli.yaml"
```

参数说明：
- --fqbn：指定开发板型号 (esp32:esp32:yd_esp32s3_n8r2)
- 项目路径：包含 .ino 文件的文件夹路径
- --config-file：指定配置文件

3.2 上传命令

```powershell
$env:ARDUINO_DATA_DIR = "D:\Arduino\Arduino15"
"D:\Program Files\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe" `
  upload --fqbn esp32:esp32:yd_esp32s3_n8r2 "D:\servotest\YourProject" `
  --port COM17 `
  --config-file "C:\Users\tt\.arduinoIDE\arduino-cli.yaml"
```

参数说明：
- --port：指定串口端口 (COM17)
- 其他参数同编译命令

3.3 查看已连接开发板

```powershell
$env:ARDUINO_DATA_DIR = "D:\Arduino\Arduino15"
"D:\Program Files\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe" `
  board list --config-file "C:\Users\tt\.arduinoIDE\arduino-cli.yaml"
```

3.4 查看已安装库

```powershell
$env:ARDUINO_DATA_DIR = "D:\Arduino\Arduino15"
"D:\Program Files\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe" `
  lib list --config-file "C:\Users\tt\.arduinoIDE\arduino-cli.yaml"
```

3.5 安装库

```powershell
$env:ARDUINO_DATA_DIR = "D:\Arduino\Arduino15"
"D:\Program Files\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe" `

```

四、项目结构要求
=====================================================

4.1 标准项目结构

```
D:\servotest\YourProject\
└── YourProject.ino    ← 文件名必须与文件夹名相同
```

4.2 多文件项目结构

```
D:\servotest\YourProject\
├── YourProject.ino    ← 主文件，必须包含 setup() 和 loop()
├── header.h           ← 头文件
├── utility.cpp        ← 源文件
└── utility.h          ← 头文件
```

4.3 重要规则

- .ino 文件必须在同名文件夹内
- 主 .ino 文件必须包含 setup() 和 loop() 函数
- 不能有多个 .ino 文件定义 setup()/loop()
- 文件夹名称和文件名必须完全一致

=====================================================
七、常见错误与解决方案
=====================================================

7.1 编译错误：undefined reference to setup()/loop()

原因：
- 文件扩展名不是 .ino
- 文件夹名与文件名不一致
- 缺少 setup() 或 loop() 函数

解决方案：
```powershell
# 确保项目结构正确
D:\servotest\YourProject\
└── YourProject.ino
```

7.2 上传错误：No such file or directory: partitions.bin

原因：
- 使用了 --build-path 参数，上传时找不到编译产物

解决方案：
```powershell
# 编译时不要使用 --build-path
arduino-cli compile --fqbn esp32:esp32:yd_esp32s3_n8r2 "D:\servotest\YourProject"
# 直接上传，CLI 会自动找到编译产物
arduino-cli upload --fqbn esp32:esp32:yd_esp32s3_n8r2 "D:\servotest\YourProject" --port COM17
```

7.3 连接错误：Could not open port COM17

原因：
- 开发板未连接
- 端口被其他程序占用
- USB 驱动未安装

解决方案：
```powershell
# 检查连接状态
arduino-cli board list

# 如果端口被占用，关闭其他串口工具
```

7.4 编译错误：library not found

原因：
- 缺少依赖库

解决方案：
```powershell
# 安装所需库
arduino-cli lib install "Adafruit NeoPixel"
```

=====================================================
八、操作流程
=====================================================

8.1 标准操作流程

```
1. 编写/修改 .ino 文件
    ↓
2. 编译代码 (compile)
    ↓
3. 检查编译结果
    ├─ 成功 → 继续上传
    └─ 失败 → 修复错误，重新编译
    ↓
4. 上传代码 (upload)
    ↓
5. 检查上传结果
    ├─ 成功 → 完成
    └─ 失败 → 检查端口和连接，重新上传
```

8.2 完整示例

```powershell
# 1. 设置环境变量
$env:ARDUINO_DATA_DIR = "D:\Arduino\Arduino15"

# 2. 编译
& "D:\Program Files\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe" `
  compile --fqbn esp32:esp32:yd_esp32s3_n8r2 "D:\servotest\RGB_Breathing_Led" `
  --config-file "C:\Users\tt\.arduinoIDE\arduino-cli.yaml"

# 3. 检查编译是否成功
if ($LASTEXITCODE -eq 0) {
    Write-Host "编译成功"
    # 4. 上传
    & "D:\Program Files\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe" `
      upload --fqbn esp32:esp32:yd_esp32s3_n8r2 "D:\servotest\RGB_Breathing_Led" `
      --port COM17 `
      --config-file "C:\Users\tt\.arduinoIDE\arduino-cli.yaml"
} else {
    Write-Host "编译失败"
}
```
