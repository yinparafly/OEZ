# 需求日志 — 2026-07-18 磁编与扑翼 ESP32 控制

> 编码 UTF-8。记录目标、已完成与待办，便于后续合板与闭环。

## 一、需求 / 目标

### 1.1 磁编读取与 PC 显示
- AS5047P（及后续 5012）经 SPI 接 ESP32-S3，读取电机相位。
- PC 端显示：角度 0–360°、弧度 0–2π；记录 RPM vs 时间；相位钟表可视化。
- 通信：串口高波特率（921600）；采样链路 1600Hz 过采样平滑 → 400Hz 输出。

### 1.2 供电与电平
- 磁编板供电范围 3.3–5V；与 ESP32 对接时使用 **3.3V**。

### 1.3 5012（TLE5012B）
- 提供独立读取工程；另提供与 AS5047P 可切换的兼容测试固件，便于换芯片验证。

### 1.4 扑翼控制架构（均由 ESP32 控制）
| 项 | 约定 |
|----|------|
| 控制环 | 400Hz |
| 磁编平滑 | 1600Hz 过采样 → 400Hz |
| 扑翼轨迹 | 上慢下快非对称正弦 |
| 霍尔参考 | 0° / 180° |
| 减速比 | ≈29（**精确值待确认**） |
| 外端舵机 | 2 路，PWM **50Hz** |
| 电调 | PWM **400Hz** |
| 算力 | 单 ESP32-S3 负担评估：**够用** |
