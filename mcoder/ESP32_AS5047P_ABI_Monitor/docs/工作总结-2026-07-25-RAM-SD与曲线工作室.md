# 工作总结 · 2026-07-25 · ABI 短时记录 / SD / 曲线工作室

## 目标

弹射类短时转速：约 2 kHz × 1～2 s，可靠落盘；避开此前 USB 文本大包回传易复位的问题。

## 已落地架构

```
MONITOR 武装 → 环缓临时存
  → |RPM|>10 且 I 过 1 圈触发
  → 回溯 400 点 + 再记 2 s → INTERNAL RAM
  → ALIVE → SD SAVE（带墙钟文件名）
  → USB DISK ON（Native USB 只读 U 盘）/ 或拔卡
PC 曲线工作室：Vegas 式 Cut、S 积分、数字转速微分求 a
```

固件：`FW=monitor-v25-timestamp`（TinyUSB MSC + CST-8 时间戳）。

## 固件要点

| 项 | 说明 |
|----|------|
| 触发 | 环缓；`|RPM|>10` + I+1 圈；回溯 400 + REC 2 s |
| 存储 | RAM → `/snap_YYYYMMDD_HHMMSS_n.bin` + 同名 `.txt` 元数据 |
| 对时 | PC 连接 / 武装发 `TIME`；未对时文件名用 `b<millis>` |
| 读卡 | `USB DISK ON` → Native USB 只读盘；串口仍走 CH343 |
| 直采 | `REC NOW` 仍可用（无门限，调试） |

SPI SD：CS=10 SCK=12 MOSI=11 MISO=13。

## PC 要点

- `abi_monitor.py --usb`：武装、日志、打开 bin
- 长采面板默认收起
- **曲线工作室**（独立窗）：Cut 切开 / 删段、RPM·S·a 单图或三线归一化
- 数字微分默认 `ma_central` + 窗 21（≈10 ms@2 kHz）；❓ 查看方法备注
- `snap_to_csv.py`：命令行导出含 S/a 的 CSV
