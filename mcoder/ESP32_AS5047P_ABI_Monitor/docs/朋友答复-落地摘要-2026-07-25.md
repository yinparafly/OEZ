## 朋友结论（同意并已按此改）

1. **不要把 PC 的「持续 GATT READ + 去重」照搬到 Android**  
   Windows 需要 READ 补 Notify 丢包；Android 上 READ 常读到 Notify 缓存 → 重复包 → CRC 挂。
2. **Dump 期间只用 Notify**；仅超时（约 500ms 无新包）才救援 READ 一次。
3. **不要 `CONNECTION_PRIORITY_HIGH`、不要自动重连**（此前已去掉，保持）。
4. **流分离正确**（武装后停实时转速）。
5. **RAM 空但 SD 有数据**：高度怀疑再次 `MONITOR START` 清了 RAM；已加 `# MONITOR START count=N` 便于核对。
6. **拉数前 `SNAP?`**：`valid=0` 直接走 SD，勿硬拉空 RAM。
