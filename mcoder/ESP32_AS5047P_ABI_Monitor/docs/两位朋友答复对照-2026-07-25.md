## 朋友2 额外要点（已吸收）

1. Android 同一时刻只能一个 pending GATT → 继续用 `opQ` 串行。  
2. DUMP 不要 40ms 狂 READ（与朋友1一致）。  
3. empty RAM 优先查二次武装，采样拖死次之。  
4. 短期接受 SD 回退；长期仍 RAM 优先。
