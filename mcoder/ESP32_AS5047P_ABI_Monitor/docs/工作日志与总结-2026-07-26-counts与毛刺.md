## v40 定稿要点

- Magic：`0xAB1C0002`，点阵 16B：`t_us` + `counts(i64)` + `index_n`
- 上位机默认：`HOST_VEL_WIN=32`，公式  
  `rpm = (Δc/4000)*(1e6/Δt)*60`（无 EMA；橙线再平滑）
- ESP32 **live** 仍保留窗+EMA，记录中也更新，供将来电机闭环
- 默认正式段 **1 s**（`REC MS` 可改）；采样仍 **2 kHz**
- Android：`1.9.5-counts-bin`；PC：帮助文件 `pc/help/转速计算方法.md` 打进 exe
- 兼容旧 `0xAB1C0001` 文件

## ABI / 采样结论（说明书对照）

- AS5047P ABI：十进制默认 **1000 PPR → 4000 steps**；二进制 **1024 PPR → 4096**
- PCNT 连续计边沿，2 kHz 够弹射曲线；不必为 1k/10k RPM 强升 4 kHz
- 与 DSP 测周比：中高速/弹射够用；极低速光滑瞬时转速测周更优
