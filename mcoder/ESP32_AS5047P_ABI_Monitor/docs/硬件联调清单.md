## 0. 回来先开 UI（推荐）

```powershell
cd E:\OEZCON\mcoder\ESP32_AS5047P_ABI_Monitor\pc

```

或 `run_ble.bat`。喇叭会正式播报（不加「测试，测试」）。

语音约定：
- 正式：`探测到了` / `请加油` / `记录完毕`
- 仅冒烟脚本的系统步骤才说：`测试，测试，xxxx`

## 1. 蓝牙监控 → 加油 → 取数

1. 扫描并连接 `OEZ-ABI`
2. 点 **开始监控** → 应听「已经开始监控，请加油」
3. **拧电调加油**（|RPM|>10 且过 I 一圈）
4. 应依次听：`探测到了` → `开始记录…` → `记录完毕` → `已存入存储卡`
5. 自动 `DUMP BIN BLE`（从 **RAM**，不读卡）→ 「数据已取回，共 N 个点」
6. 曲线工作室可打开看 RPM / S / a

失败时：看界面日志里是否有 `BLE PULL READY`、`BIN BLE BEGIN/END`、CRC 错。

## 2. USB 回归（可选）

出问题可从 `backups/usb-msc-stable-2026-07-25/` 恢复。
