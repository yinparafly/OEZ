## 1. 一句话结论

两位朋友都认为：**「行程校准 → 测量建前馈表 → 前馈+PI 闭环」方向正确**；扑翼阶段要加强**相位相关负载补偿**与**电流/安全**；当前需求文档还缺几项与整机架构的对齐（减速比、霍尔、舵机、电流）。

## 2. 两人高度一致（可直接采纳）

| 议题 | 共识 |
|------|------|
| 控制结构 | 前馈查表 + 插值 + PI 修正；PI 限幅防积分饱和 |

## 4. dp 特别指出的架构缺口（必须回答）

这两项不澄清，2000 RPM 与安全上限可能完全算错：

1. **减速比是否 ≈ 29？**  
   - 需求里的 **2000 RPM 是电机端还是扑翼输出端？**  
   - 若是输出端 2000 → 电机端约 **58000 RPM**，对多数航模电机可能不安全。

2. **是否有 0°/180° 霍尔？**  
   - 扑翼总结里有；当前转速需求文档只有 AS5047P。  
   - 有霍尔：可用于相位复位、防减速比累积漂移。  
   - 无霍尔：需明确磁编码器如何当绝对相位参考。

3. **舵机 50 Hz×2 是否同一块 ESP32？**  
   - 若是，要规划 LEDC/定时器资源，与电调 400 Hz 分开。

4. **电调型号 / 是否 BLHeli_32？** → 决定继续 PWM 还是上 DShot。  

5. **电机 KV + 电池几 S？** → 决定 RPM 硬上限：`KV × V × 0.8`。  

6. **有无电流传感器？**  
   - 两位都强调扑翼下电流重要；无则建议加 ACS712/INA219 等。

## 5. G 特别强调的扑翼控制点

- ESP32 侧做 400 Hz 闭环、与飞控解耦 —— 认可现架构方向  
- 将来：`PhaseSync` + 霍尔复位，防 29:1 累积漂移  
- 负载转矩前馈：用扑翼相位 θ 叠加补偿（比纯 PI 追更合适）  
- 实时性：控制环应用硬件定时器 / 高优先级任务，减少 `loop()` 抖动  
- 变频飞行时，负载系数随 ω 变化比「死两套表」更鲁棒  

（这些多为**扑翼联调阶段**，不阻塞当前空载测量。）

## 6. 建议冻结的参数默认值（吸收双方意见）

| 参数 | 建议默认 | 备注 |
|------|----------|------|
| ESC PWM | 400 Hz，1000~2000 μs | 上电先 1000 |
| 空载测量上限 | ≤1600 μs | 另用 RPM 软上限 |
| 测量步长 | 先手动，再自动 20~50 μs | 停留 2~3 s |
| 前馈表 | 约 20~50 点线性插值 | 静态数组，禁动态分配 |
| 缓启动 | 500 RPM/s | 可调 200~2000 |
| 心跳 | 200 ms；超时可配 500~1500 ms | PC 主动 PING |
| 超速 | max(1.2×目标, 目标+200) | 进故障锁 |
| PI 修正限幅 | ±100 μs | dp 建议 |
| 积分条件 | 仅闭环且 \|e\|&lt;100 RPM 时累积 | dp 建议 |
| 怠速 | 默认关（1000=停） | 可选 IDLE_US |
