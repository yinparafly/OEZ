# 扑翼霍尔接线 · 2026-07-21

## 采用模块（项目定型）

资料下载：http://pan.baidu.com/s/1qYfBwQw  

品名参考：**传感器模块 / 霍尔传感器 / 测速传感器 / 计数传感器**（LM393 + **A3144** 霍尔）。

### 一、模块说明

| 项 | 内容 |
|----|------|
| 尺寸 | 约 2.7 cm × 1.4 cm（资料写 1.4mm，按常见小板理解） |
| 主要芯片 | **LM393** 比较器 + **3144** 霍尔传感器 |
| **工作电压** | **直流 5 V（VCC 必须接 5V，不要接到 3.3V）** |

### 二、模块接口（4 线制，本项目用 3 根）

| 丝印 | 接法 | 说明 |
|------|------|------|
| **VCC** | **外接 5V** | 模块额定直流 5V；与 ESC/编码器供电规划时单独确认电流，**勿用 ESP32 的 3.3V 脚供电** |
| **GND** | ESP32 **GND**（与模块共地） | 必须共地 |
| **DO** | 数字量输出 0/1 → ESP32 GPIO | 见下节电平与耐压 |
| （第 4 线） | 部分板为 AO/空 | 本项目只用 **DO** |

### 三、模块特点（摘自商家说明）

1. 有电源指示灯和信号输出指示。  
2. 单路信号输出。  
3. 灵敏度可调（精调电位器）。  
4. 商家文案曾写「无触发低 / 有触发高」——**与厂商 51 样例不符，以样例为准**。  
5. 有磁场切割就有信号输出。  
6. 输出开关量，可接单片机 / 继电器等。

### 厂商 51 测试程序结论（`3144hall/.../传感器51测试程序/1.c`）

```c
sbit key1 = P0^1;
if (key1 == 0) {          // DO 为 0 视为触发
    delay();              // 消抖
    if (key1 == 0) {      // 再次确认
        SBUF = 0x01;      // 串口报一次
    }
}
```

→ **触发 = DO 低电平（低有效）**。ESP32 固件默认 **`HALL ACTIVE LOW`**，并做双采样消抖。若你板实测相反，再发 `HALL ACTIVE HIGH`。

### 四、与 ESP32-S3 接线（本台架）

| 信号 | 含义 | ESP32 引脚 | UI 颜色 |
|------|------|------------|---------|
| 下扑起点（输出盘 **0°**） | 开始下扑 · 模块 DO | **GPIO4** | 橙 `#E07A3D` |
| 上举（约 **180°**） | 上举 · 模块 DO | **GPIO5** | 蓝 `#2B7FD4` |
| 电调信号（既有） | PWM | GPIO9 | — |
| 编码器 SPI（既有） | CS/SCLK/MISO/MOSI | 10 / 12 / 13 / 11 | — |

```text
模块 VCC ──► 5V 电源（与板子供电同系统地）
模块 GND ──► ESP32 GND
下扑 DO  ──► GPIO4   （经电平处理，见下）
上举 DO  ──► GPIO5
```

**耐压注意（必读）**  
ESP32-S3 GPIO 为 **3.3V**。本模块 VCC=5V 时，DO 高电平常接近 **5V**，**不可直接硬接 GPIO**。任选其一：

- DO → **电阻分压**（例 10k 上 + 20k 下）→ GPIO；或  
- DO → **电平转换**（5V→3.3V）→ GPIO。  

共地后用万用表确认 GPIO 侧高电平 ≤ 3.3V 再上电跑固件。

GPIO4 / GPIO5 **不被 USB 串口占用**（USB 为 19/20 或 UART0 的 43/44）。

## 减速比（固件已写入）

```text
设计减速比 i_design = (59×79)/(12×14) = 4661/168 ≈ 27.744
（仅作对照，不作显示换算）

实测：
  输出频率 out_Hz = 1 / T_下扑沿周期   （霍尔 GPIO4 两次触发间隔）
  减速比   i_meas = |Δ电机展开角| / 360°   （同一盘转内电机转数）
界面同时显示电机编码器 RPM、霍尔实测 out_Hz，以及 i_meas vs i_design 偏差%
```

下扑霍尔边沿自动把当前电机展开角标为盘 0°；也可用 PC「HALL CAL」或指令 `HALL CAL`。上举相对 0° 约 180°，安装偏角用磁编码 `disc_est` 反算校准。

## 指令

- `HALL?` — 电平、计数、最近电机角/盘相位  
- `HALL CAL` — 当前电机角 → 盘 0°  
- `HALL ACTIVE LOW|HIGH` — 本模块默认 **LOW**（同 51 样例）；实测相反再改 HIGH
