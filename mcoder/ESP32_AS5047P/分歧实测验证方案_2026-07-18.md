**每次通电前**

- [ ] 卸桨 / 固定；人远离旋转面  
- [ ] ESP 已输出 **1000 μs** 再给电调动力电  
- [ ] 急停可用（Esc）；**只开一个** PC 工具占串口  
- [ ] 预检：`ctrl_hz ≥ 200`，否则不给油  

**转速软上限（修订）**

| 阶段 | 原方案 | **现方案（空载已验证）** |
|------|--------|---------------------------|
| 频率摸底 T1′ | ≤800 RPM | 开环探点脉宽 **1100 μs**（约数百~千转级，以编码器为准）；**不转即停** |
| 闭环验收 | ≤2000 | **可测至 6000**（阶梯 1000…6000），报告必须标 **空载** |

**通过总原则（增补）**

- 编码器 **|rpm|≥40** 视为「已转动」（与扫频/学习一致）  
- 急停 / 失败 → **PWM 1000 + FREQ 50**（安全默认）  
- 报告标明：**空载 noload**；扑翼结果不得与空载混表

## 3. 试验 T1′ — PWM 刷新率扫描（修订，裁定 D4）

> 取代初版「人工逐频 + 主观异响」为主的流程；**以磁编码器是否在时限内转动为硬判据**。

### 目的

确认各 `FREQ` 下电调是否响应；得到**最高可用刷新率**与**默认工作频率**。

### 硬规则（来自实测要求）

1. 每档：停转确认 → `FREQ=f` → 开环 `PWM=探点`（默认 **1100 μs**）  
2. **判转时限：默认 3 s**（可设 5 s）；时限内 `|rpm|` 峰值与后半均值达不到阈值 → **FAIL**  
3. **FAIL 立即**：`PWM 1000` + **`FREQ 50`** + `STOP`；**不再测更高频率**  
4. 分析口径：  
   - **50 Hz 就 FAIL** → 台架/供电/校准/脉宽/编码器问题，**不是**「高频不支持」  
   - **50 PASS、100 FAIL** → 该电调/连线不支持 ≥100 Hz 本试验条件；默认工作 **50 Hz**  
5. PASS 档可与 50 Hz 基线比转速偏差（±10% 或 ±50 RPM）；偏差大标 MARGINAL，不自动升默认频  

### 自动化

```text
python auto_freq_test.py --port COM10 --hold 3 --pulse 1100
```

UI：频率调试 →「一键自动扫频」；失败同样回 50 Hz。
