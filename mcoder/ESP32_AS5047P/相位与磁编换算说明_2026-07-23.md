# 相位与磁编换算说明（2026-07-23）

本文说明输出盘相位 `disc` 如何由 **霍尔绝对标记** + **电机磁编累计计数** 合成，以及为何互质齿必须每次霍尔重锁。

相关代码：`firmware/ESP32ReadAS5047P/ESP32ReadAS5047P.ino`  
- `encSampleCb`：raw 差分解缠 → `enc_cb_counts`（堆叠坐标）  
- `discLatchHall` / `discEstFromMotor`：霍尔锁存与盘角估计  
- 停机策略：`相位停机说明_2026-07-22.md`

---

## 1. 为什么互质齿必须每次霍尔重锁？

减速链齿数 **12、14、59、79** 互质（整体比 `4661/168 ≈ 27.744`）。  
电机轴转一整圈时，输出盘只转约 `1/27.744` 圈；**磁编自身的绝对零点（AS5047P raw=0）与霍尔（GPIO4=0° / GPIO5=180°）的相对角关系会随圈数漂移**，不会固定。

| 做法 | 结果 |
|------|------|
| 只在第一次过霍尔时锁一次，之后永久用该参考 | **错误**：相对关系已变，盘角估计会漂 |
| **每次**有效霍尔沿重锁 `disc_ref` + 当时的累计电机坐标 | **正确**：绝对盘角由霍尔给出，霍尔之间只积分短程 Δmotor |

`hallPoll` 在 GPIO4/GPIO5 有效沿（过行程防抖后）调用 `discLatchHall(0)` / `discLatchHall(180)`，**不是**一次性校准。

## 2. 公式（盘相位）

```
disc = wrap360( disc_ref + esc_sense * Δmotor_deg / GEAR_RATIO + offset )

Δmotor_deg = (motor_unwrapped_counts - disc_ref_motor_counts) * (360 / CPR)
CPR = 16384  (AS5047P 14-bit)
GEAR_RATIO = 4661/168
disc_ref ∈ {0, 180}   // 末次霍尔：GPIO4→0，GPIO5→180
offset = disc_phase_offset_deg  // NVS hphoff，0↔180 标反时可 +180
```

等价：

```
Δmotor_counts = accumulated_counts_now - accumulated_counts_at_last_hall
disc = wrap( disc_ref + esc_sense * Δmotor_counts / CPR / gear * 360 + offset )
```

## 3. 「堆叠」电机坐标 —— 处理磁编自己过零

AS5047P 单圈 raw ∈ `[0, 16383]`，每圈会自己 wrap。若错误写成：

```
Δ = raw_now - raw_at_hall   // 错误：霍尔之间若经过 raw=0，差值会跳 ±16384
```

正确：采样回调对 raw 做 **±8192 最短弧差分**，累加到 **多圈整型计数**：

| 变量 | 含义 |
|------|------|
| `enc_cb_counts` | 采样任务内的 **堆叠/展开** 累计 counts（raw wrap 已消化） |
| `motor_unwrapped_counts` | 控制环 snapshot 拷贝的同一堆叠坐标（盘相位主用） |
| `motor_unwrapped_deg` | `counts * 360/CPR`，浮点展开角（诊断） |
| `disc_ref_motor_counts` | **末次霍尔** 时刻的 `motor_unwrapped_counts` |

霍尔之间：`Δmotor = motor_unwrapped_counts - disc_ref_motor_counts`，即使段内磁编多次过自身零点也不断。

```
draw = raw - last_raw
if draw >  8192: draw -= 16384
if draw < -8192: draw += 16384
enc_cb_counts += draw
```

## 4. 明确禁止的错误模型

1. **首锁永用**：第一次 Hall 后永不更新 `disc_ref_motor_*`。  
2. **单圈 raw 直接减**：不用堆叠 counts。  
3. **用磁编绝对零当盘零**：raw=0 ≠ 物理 0°（霍尔才是盘绝对标记）。

## 5. ~180°/~200° 着陆误差判定（与自学习）

停机后 `err = wrap180(disc - target)`：

| 现象 | 判定 | 处置 |
|------|------|------|
| `|err| ≈ 150~210°`（常见 ~180° 或盘读 ~200°）且重复 | **标架反了**（固件 0 ↔ 物理 ~180） | `PHASE OFFSET ±180` 后重试 |
| `|err|` 十余度～几十度 | **制动距离 / brake_k 或 lead** | 固件 EMA 学 k；或调 LEAD；REFINE 爬霍尔 |
| 过霍尔后 `motor_cnt` 不更新 / disc 跳变 | **锁存过旧或解缠异常** | 查每沿 `discLatchHall` + 堆叠 counts |

验收（目标 0°）：盘角落在 **[355°, 5°]**，尽量 `hall_confirm=1`。

## 6. 与相位停机的关系

APPROACH/BRAKE 的 `disc`/`remain` 全部来自 `discEstFromMotor()`。  
霍尔：绝对复位、0/180 确认、REFINE 对准。制动 `est_brake≈k·rpm²` 见停机说明。

## 7. 停后偏差诊断（est vs Hall）

台架脚本：pc/hold_phase_bias_learn.py

1. HOLD 停后记录 est_disc（discEstFromMotor）
2. 低速爬向目标霍尔（0°→GPIO4 / 180°→GPIO5）
3. 沿到后 hall_disc∈{0,180}，ias = wrap180(est_disc - hall_disc)
4. |bias| 大且稳定 → **估算/OFFSET**；|bias| 小而停偏大 → **策略(brake_k/lead)**
