# 相位停机朋友建议（原文整理）· 2026-07-23

> **互质齿重锁**：质数/互质齿轮(12×14 / 59×79) → 磁编绝对零相对霍尔零每圈漂移，必须每次霍尔沿重锁 disc_ref + motor_counts，禁止一次性首锁永用。

---

## 1. 核心矛盾

希望做的是「带终端约束的、单向、欠驱动系统的停车」。

- **约束**：航模 ESC 只能正向油门（约 1000–2000µs），**不能主动制动**，不能反转。
- **目标**：停在目标相位，误差约 ±5°。
- **旧策略**：壁钟软降 + 低速爬行 + 固定提前量切油 → 「靠感觉松油门，再听天由命滑行」。

**结论**：不能在 BRAKE/SETTLE 里用「位置误差 → 加大油门」做闭环修正。进入目标窗后唯一动作是松油门；再踩油门只会冲过目标。

---

## 2. 应改哪里

改 `holdPhaseTick()` 的 **APPROACH**，不要改 BRAKE/SETTLE 的「误差→油门」思路。

旧 APPROACH 不足：

1. `holdPhaseApplyCrawl(remain)`：台阶压速，无减速规划。
2. `lead_eff`：虽含 ω/RPM 项，仍是定阈值，不知真实滑行角。

---

## 3. 改造方案（已采纳方向）

把 APPROACH 做成 **在线速度规划器**（前馈 + 距离估计，不是误差反馈刹停）：

1. **学习**：BRAKE→SETTLE 成功后，记 `(RPM_brake, 滑行盘角)`，更新 `RPM→滑行角` 模型。
2. **决策**：若 `remain ≤ est_brake + margin` → 立刻切油进入 BRAKE。
3. **否则**：按剩余距离算安全 `desired_rpm`（时间常数法），CLOSED 跟踪。

模型可选：

- **方案 A**：小表 RPM→coast_deg，插值。
- **方案 B**：`coast ≈ k · rpm²`，在线 EMA 更新 `k`（实现选用，更简单）。

`desired_rpm` 示意（盘° → 电机 RPM；实现用物理正确换算）：

```text
desired_rpm = (remain / tc) * (GEAR_RATIO / 6)   # tc≈1.5s，夹 [40, crawl_max]
```

（朋友原文 `* (GEAR * 6)` 为单位笔误；固件用 `/6`。）

---

## 4. 边界

- 保留 `stop_rpm` 与 BRAKE→SETTLE 延时；规划只负责对准，末段仍靠滑行消化。
- `stop_ms` 软降保留为高速斜坡**限幅**，不作主刹停律。
- **REFINE**（0°/180° 霍尔爬行）必须保留作最后防线。
- **禁止**在 BRAKE/SETTLE 按误差加油门。
