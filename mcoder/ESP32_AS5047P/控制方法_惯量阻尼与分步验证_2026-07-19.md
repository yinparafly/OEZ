## 1. 问题陈述

当前台架：**电机空载**，几乎只有转子惯量 \(J\)，粘性阻尼 \(B\) 很小，无外部负载转矩。

同一目标转速附近，两种工况动力学不同：

| 工况 | 例 | 物理 | ESC 能力 |
|------|----|------|----------|
| 加速 | 1000 → 2000 RPM | 需克服 \(J\alpha\)，「推上去」 | 加油门有效 |
| 减速 | 3000 → 2000 RPM | 动能靠摩擦/风阻耗散，「掉得慢」 | 多数航模 ESC **非主动制动**，减油门≠强制动 |

因此：**升速与降速的控制逻辑不应强制对称**（对称 SOFT RATE + 单套 PI 容易在减速段积分乱动、加速段追不上）。

经典刚体方程（伺服文献通用）：

\[
T \approx J\,\alpha + B\,\omega + T_d
\]

工业做法通常拆成：

1. **轨迹层**：指令斜坡升/降速率可不同  
2. **前馈层**：加速度/速度前馈 \(K_J\dot\omega^* + K_B\omega^*\)（跟踪）  
3. **反馈层**：PI/PID 管扰动与模型误差（抗扰）  
4. **调度层**：按转速或按加速/减速选增益（非线性）

参考（理论与产品，非本仓库代码）：

- Parker《Servo Fundamentals》：前馈 \(J\alpha+B\omega\) + PID 抗扰  
- Roboteq Acceleration Feedforward：\(T = B\omega + J\alpha\)  
- VESC：`ramp_time_pos` / `ramp_time_neg` 不对称斜坡  
- SimpleFOC：PID + 抗饱和 + `output_ramp`（思路可抄，**不能直接换上**——要 FOC/电流环，我们是 ESC 脉宽）

**现成库结论**：没有「AS5047P + 航模 ESC」开箱惯量库；在现有固件上分步加特性最合适。

## 2. 我们已有的控制栈（截至本备忘）

```text
目标 RPM
  → 缓启动斜坡 target_ramped（原：单一 soft_rate）
  → 开环：ThrottleMap 前馈 pulse = f(rpm)
  → 闭环：pulse = FF(rpm) + PI(e)   [可选 GainMap 按转速插值 Kp/Ki/Kd]
编码器 AS5047P → rpm 反馈
```

已具备：

- 稳态 **前馈 map**（台阶 / 斜坡学习）  
- **分区 PID（GainMap）** 按转速调度  
- 对称 **SOFT RATE**（升=降）

尚未具备（本备忘后续步骤）：

- 升/降不同斜坡  
- 加速度前馈（脉宽域）  
- 按加速/减速选增益

## 3. 分析过程（每次改动怎么验）

### 3.1 通用安全

- 卸桨 / 固定；RPMMAX 设好；Esc 急停可用  
- 先开环或低目标，再闭环  
- 一次只改 **一个** 新自由度，其它固定  

### 3.2 对比试验模板（加减速不对称）

固定：profile、前馈图、PID/GainMap、电调频率。

| 试验 ID | 指令轨迹 | 记录 | 看什么 |
|---------|----------|------|--------|
| A1 | 停 → 1000 → 2000（升） | t, target, rpm, pulse | 上升时间、超调、稳态误差 |
| A2 | 3000 → 2000（降） | 同上 | 下降时间、是否「减油门但转速掉不动」、积分是否冲大 |
| A3 | 2000 稳态保持 10 s | 同上 | 稳态脉宽、抖动 |

判据（空载、先宽松）：

- 升：进入 ±10% 目标带的时间；超调 < 15%  
- 降：进入带宽时间；若 pulse 已接近前馈仍长时间偏高 → **惯性滑行主导**，应降 `rate_down` 或减弱减速段 Ki  
- 不得触发 overspeed ESTOP  

日志：PC 录 CSV 或串口遥测；对比改参数前后同一 A1/A2。

### 3.3 辨识顺序（避免参数耦合）

```text
① 只建/用前馈图（开环跟得上再谈闭环）
② 只调指令斜坡（对称 → 不对称）
③ 再调全局或分区 PI（稳态）
④ 再加加速度前馈 Ka（动态）
⑤ 最后才做「加速/减速两套增益」
```

每层通过后再开下一层；失败则回退一层，不要同时拧五个旋钮。

## 4. 分步路线图（简单 → 可辨识）

### 步骤 S0 — 基线（已完成，只记录）

- 斜坡/台阶学习 → ThrottleMap + GainMap  
- 闭环试转：死区导致 300 难起 → 优先 1000 再升  
- **验证**：开环台阶能转；学完 `GAIN?` 有表  

### 步骤 S1 — 指令层：升/降不同斜坡  ← **当前优先**

**做什么**

- `SOFT RATE UP <rpm/s>` / `SOFT RATE DOWN <rpm/s>`  
- `SOFT RATE <x>` 兼容：同时设升=降=x  
- UI：升速率、降速率两个框  

**为何先做**：不改 PI、不改 map；只改轨迹形状；空载减速「掉得慢」时，降速斜坡放缓最直观。

**验证**

1. UP=800, DOWN=800：A1/A2 作对称基线  
2. UP=800, DOWN=300：A2 下降应更跟得上（PI 少「假动作」）  
3. 若 DOWN 再慢仍掉不动 → 记录「滑行主导」，进入 S2 时不要猛加减速 Ki  

**通过标准**：A1/A2 各 3 次可重复；无 ESTOP；操作者能说出「降比升慢是否改善」。

### 步骤 S2 — 脉宽域加速度前馈 \(K_a\)

**做什么**

\[
\Delta pulse_{ff} = K_a \cdot \dot\omega^*_{\mathrm{cmd}}
\]

仅用 **指令** 斜坡的导数（已知），不估真实 \(\alpha\)（噪声大）。

**验证**：固定 S1 斜坡；Ka=0 vs Ka>0；看 A1 上升时间是否缩短、A2 是否少超调。  
**辨识 Ka**：斜坡学习段 \(\Delta pulse / \Delta(\mathrm{d}rpm/\mathrm{d}t)\) 粗估，再台架微调。

### 步骤 S3 — 减速段积分限制 / 可选 accel·decel 增益

仅当 S1+S2 仍不够：

- 减速时减小 Ki 或收紧积分限幅  
- 或 GainMap 增加「加速表 / 减速表」两维（**慎用**，参数翻倍）

### 步骤 S4 — 有扑翼负载后再做

- 重学 flap 前馈 + GainMap  
- 再考虑周期负载 / 相位前馈（原试验 T3b）  
- 有电流后再把 \(K_a\) 从「脉宽」升格为「等效转矩」
