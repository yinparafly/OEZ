| **采集** | SPI 读编码器 | **2000 Hz**（esp_timer） |

## 6. 安全约束（硬性）

| 约束 | 说明 |
|------|------|
| **HOST_TIMEOUT** | 默认 **1.5s** 无主机指令且运行中 → `ESTOP host_timeout`。豁免：`FLIGHT` / `LEARN` / **板内 TEST** / **`HOST OFF`（或 `HOST TO 0`）**。台架长测优先 HOST OFF 或 TEST。 |
| **单占 COM** | 同时只一个进程占 COM10；测时禁 flash、禁第二 agent/monitor；用 `com_port_guard`。 |
| **实时禁打印** | **禁止**在 2k 采集回调或 400 控制任务里 `Serial.print` / 同步 `hostPrintf`；日志走异步环 + 20Hz 遥测。 |
| **有效区 ≥2000 RPM** | 低速无气动意义且易顿挫；门闩/冒烟从 **2000** 起；勿在低速频繁启停。 |
| **判转** | **编码器主判** + **霍尔辅判**（`motor_spin_detect` / 板载 TEST 同逻辑）；编码器过即可认电机轴在转。 |
| **异常** | ESTOP → 油门 **1000µs**；脚本结束释放 COM 锁。 |
| **PC 保活** | 未关超时时 ≤0.5s 重发；或 `HOST OFF` 后低频观测。 |
