# ESP32 蓝牙版：电机 + 磁编码器台架（非听声测转速）

**用途**：PC 与台架有距离时，用 BLE 遥控/监视 **ESP32-S3 + AS5047P + 航模电调**。  
**不是** Android `MotorPitchRpm`（麦克风 FFT 听声测转速）；声音程序仍在  
`android/MotorPitchRpm/`，与本蓝牙栈无关。

## 组成

| 端 | 路径 |
|----|------|
| 固件 | `firmware/ESP32ReadAS5047P/`（`ble_host.h` + `.ino`） |
| PC UI | `pc/encoder_monitor.py`（链路选 **BLE**） |
| BLE 库 | `pc/ble_link.py`（依赖 `bleak`） |

设备广播名：**OEZ-RPM**（Nordic UART Service）。

## 烧录

用 Arduino / arduino-cli 烧录 `ESP32ReadAS5047P.ino`（需开启蓝牙的 ESP32-S3 板支持包）。  
串口调试仍可用；上电后应看到：

```text
# BLE name=OEZ-RPM NUS rate_default=20Hz lite=1
```

## PC 使用

```text
cd pc
pip install -r requirements.txt
python encoder_monitor.py --ble
```

或打开 UI 后：链路选 **BLE** → **刷新** → 选 `OEZ-RPM […]` → **连接**。

- 仍须周期性 **PING**（UI 已做），否则运行中会 host_timeout 急停。  
- Windows 本机需蓝牙适配器；与台架距离以实测为准（障碍会明显掉包）。

## 带宽不够时（降传输量/频率）

固件默认 BLE：**20 Hz + 瘦身行**。

| 指令 | 作用 |
|------|------|
| `BLE?` | 查询连接/速率/瘦身 |
| `BLE RATE 10` | 遥测 5~50 Hz（UI 顶栏 BLEHz） |
| `BLE LITE ON` | `B,t_ms,rpm,pulse,target,mode,run`（默认） |
| `BLE LITE OFF` | 兼容字段（仍限速） |

USB 侧仍为 **250 Hz 完整 CSV**；只有 BLE 限速。  
卡顿/掉线：先降到 **10 Hz**，保持 **瘦身 ON**，关掉无关曲线刷新负荷。

## 协议

指令与 USB 相同（`RPM` / `START` / `STOP` / `ESTOP` / `MODE` …）。  
BLE 遥测瘦身：

```text
B,<t_ms>,<rpm>,<pulse>,<target>,<mode>,<run>
```

ACK/`#` 行会尽量同步到 BLE，便于 UI 显示指令反馈。
