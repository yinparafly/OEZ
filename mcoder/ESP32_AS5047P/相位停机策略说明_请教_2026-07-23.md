## 0. 已采纳改造（2026-07-23）

朋友核心判断已采纳并写入固件：

| 原则 | 落地 |
|------|------|
| ESC 无主动刹 → **禁止** BRAKE/SETTLE 里误差→加油门 | 切油后仍只保持 1000µs，等 `stop_rpm` / 延时 |
| 改造重心在 **APPROACH** | `holdPhaseApplyPlan` + `getEstimatedBrakeAngle` |
| 主切油律 = 距离 | `remain ≤ max(est_brake + tol, lead_eff)` → `BRAKE`（`est_brake` 优先；旧 lead 作安全二次触发） |
| 速度指令 = 剩余角规划 | `desired_rpm = (remain/tc)·(gear/6)`，夹 `[40, crawl_max]`，**CLOSED** 跟踪 |
| 学习滑行模型 | Scheme B：`est ≈ k·rpm²`；成功 DONE 后用 `(rpm_at_brake, coast_disc)` EMA 更新 `k`（NVS `hpbk`） |
| `stop_ms` | 仅高速软降**斜坡限幅**，非主刹停律 |
| REFINE | 仍保留：0°/180° 首停 miss / 无 hall_confirm 时霍尔爬行救场 |

命令：`PHASE PLAN?` · `PHASE PLAN TC <s>` · `PHASE BRAKEK [k]|SAVE|?`；`PHASE?` 增 `est_brake` / `desired_rpm` / `brake_k`。

下文 §1 起保留改造前「请教」叙述便于对照；**以 §0 + 当前 `.ino` 为准**。

## 1. 一句话结论（改造前快照）

**改造前**是「开环/半开环预置提前量 + 阈值触发切油」。

**改造后**：APPROACH 为「在线滑行距离估计 + 时间常数速度规划 + 闭环跟速」；仍**不是** BRAKE 段误差反馈。

| 段 | 改造前 | 改造后 |
|----|--------|--------|
| 软降 | 壁钟线性 RPM | 仍保留，仅作高速斜坡限幅 |
| 接近 | 开环台阶爬行 | CLOSED 跟 `desired_rpm(remain)` |
| 切油 | `remain ≤ lead_eff` | `remain ≤ max(est_brake+tol, lead_eff)` |
| 制动后 | 被动滑行 | 同左（禁止误差→油门） |

## 3. 状态机

`APPROACH` → `BRAKE` → `SETTLE` →（可选）`REFINE` → …

### APPROACH（改造后）

1. 可选软降：`rpm0→crawl`，期间不切油。  
2. 软降完：`est=k·rpm²`；`cut=max(est+tol, lead_eff)`；到位则 `BRAKE`，否则 `holdPhaseApplyPlan`。  
3. 霍尔已到尚未切油 → `hall_*_before_plan`。

### BRAKE / SETTLE / REFINE

不变：1000µs 滑行；`stop_rpm`/延时；0/180 REFINE 爬霍尔救场。

---

## 4. 模型参数

```text
est_brake = clamp(k * rpm², 2°, 80°)     // NVS hpbk
lead_eff  = lead_deg + ω·(lead_ms/1000) + lead_rpm_k·|rpm|
cut       = max(est_brake + tol, lead_eff)
desired   = (remain / tc) * (gear / 6)   // NVS hptc，夹 [40, crawl]
```

| 参数 | 默认 | NVS |
|------|------|-----|
| `brake_k` | 0.0008 | `hpbk` |
| `plan_tc` | 1.5 s | `hptc` |
| `lead_*` | 同前 | `hplead*` |
| `tol` | 5° | RAM |
