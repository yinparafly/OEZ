## 实时路径禁打印（硬约束落实）

**用户约束**：绝对禁止在 **2kHz 采样回调** 或 **400Hz 控制任务** 中调用 `Serial.print` / `hostPrintf` / 任何阻塞串口输出（921600 下约 150B≈1.3ms，会吃掉 400Hz 的 2.5ms / 撑爆 2k 的 500µs）。

| 项 | 状态 |
|----|------|
| `encSampleCb` | 零打印；`hostEnter/ExitRealtimeCb` 包裹，误调入环 |
| `motorControlTask` | `hostForbidPrintFromTask`；HALL/LEARN/SENSE/STOPAT 的 `hostPrintf` 仅入异步环 |
| USB 遥测 | 已取消 250Hz 满速；`USB_TELEM_HZ=20`，迁到 **低优 `telemTask@Core0`**，`Serial.write` 批量写出 |
| 异步日志 | `ble_host` 环深 48×384；`telemTask` + `loop` 调 `hostDrainAsyncLog` |
| 总纲验收项 | `双核架构与采样改造建议_2026-07-22.md` §6.2 已补「实时路径禁打印」 |

**勿**在实时路径打日志做验证；自检用 `PING` / `ENC?` / `CTRL?` / 遥测 CSV 末列 `enc_sample_hz≈2000`。
