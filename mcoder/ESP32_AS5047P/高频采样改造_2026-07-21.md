# 编码器高频采样改造（250Hz→2kHz 解耦）· 2026-07-21

台架：ESP32-S3 + AS5047P（SPI）+ 航模 ESC（GPIO9）+ 扑翼输出盘霍尔（GPIO4/5）。COM10@921600。
固件：`firmware/ESP32ReadAS5047P/ESP32ReadAS5047P.ino`（本次唯一改动的固件文件）。

> 交接摘要：编码器角度采样/测速已从 250Hz 控制环解耦到 **2kHz**（esp_timer 周期回调内同步 SPI 读），
> 控制环仍 250Hz 只取最新快照。实测采样率稳定 **2000Hz**，采样任务 CPU **≈2.5–3%**，
> 主循环空转 **~70–100kHz**（余量极大）。高转速测速**不再折叠**：2000/4000/6000RPM 稳态与霍尔盘频交叉误差 **0.0–0.6%**，
> 并越过旧 7500RPM 折叠界（实测到 ~7300RPM 仍与霍尔吻合 0.3%）。已编译（exit 0）并烧录 COM10。

---

## 1. 背景与目标

- 原实现：测速在 250Hz 控制环里 `readAngleCom()`（SPI 2MHz，每帧后 `delayMicroseconds(1)`），
  角度差分 `unwrapDeltaDeg` 解缠依赖「相邻样本 <0.5 圈」。
- 250Hz → 每样本 4ms，Nyquist = 0.5rev/4ms = 125rev/s = **7500RPM**；超过即折叠（读数塌陷/乱跳）。
- 已放开 `RPMMAX=12000`、`MOTOR_RPM_ABS_MAX=12000`，但 250Hz 采样物理上测不了 >7500RPM。
- SPI 物理上远快于 250Hz（一帧~10µs），瓶颈是**控制环节拍**，而非 SPI。
- **目标**：把编码器采样/测速从控制环解耦到 **≥1kHz（目标 1–2kHz）**，突破 7500RPM 折叠，
  支持测到 12000RPM（Nyquist@2kHz=60000RPM，远够），且 CPU 负担极轻，控制环/遥测无感切换。

---

## 2. 方案选型与理由

| 方案 | 结论 | 理由 |
|------|------|------|
| **esp_timer 周期回调 + 同步 SPI 读**（采用） | ✅ 最终采用 | 精确到 µs 级周期（不受 FreeRTOS tick 限制），回调运行于 esp_timer **任务**上下文（非硬 ISR），可安全调用 SPI（`transfer16`）。实现简单、稳定、CPU 极低。 |
| `vTaskDelayUntil` 高优先级任务 | ✗ 未采用 | Arduino-ESP32 `configTICK_RATE_HZ=1000`，`vTaskDelayUntil` 最小 1ms → 上限仅 1kHz，达不到 2kHz。 |
| SPI + GDMA | ✗ 暂不采用（可选增强） | 单次仅 16bit 传输，DMA 描述符/中断开销相对收益极低；Arduino-ESP32 框架下裸配 GDMA + CS 时序较繁琐、易踩坑。实测同步读仅占 **~2.5% CPU**，无必要。列为后续可选。 |
| 硬件 ABI/PCNT 正交计数 | ✗ 未采用（未来） | AS5047P 有 ABI 增量输出，配 PCNT 可实现真正零 CPU 计数，但需改接线（额外 3 线）+ 失去绝对角。列为未来方向。 |

**关键点**：esp_timer 回调是**任务分发（`ESP_TIMER_TASK`）**，不是硬中断，故回调里做 SPI 事务是允许的
（SPI 事务锁在 `setup()` 里 `beginTransaction` 一次并常驻，回调内只 `transfer16`，不再抢锁；控制环已不再碰 SPI，无并发冲突）。

### 为何不再折叠（核心原理）

- **解缠在高频侧（2kHz）完成**：每 500µs 读一次 raw，整型差分 ±8192 环绕处理后累加到 `int64 counts`。
  这一步的 Nyquist 由采样率决定：0.5rev/500µs = **60000RPM**。
- **测速用「已解缠累加计数」做窗口差分**：`rpm = Δcounts/ENC_CPR / Δt × 60`，窗口取 8 样本（@2kHz=4ms）。
  因为 `counts` 已单调解缠，长窗口差分**不会重新引入折叠**，同时又拿回了 4ms 窗口的分辨率
  （量化 ~0.9RPM/count），兼得**高量程 + 高分辨率**。

## 3. 具体改动清单（`ESP32ReadAS5047P.ino`）

1. **头文件**：新增 `#include "esp_timer.h"`。
2. **时序/配置区**（原 CTRL_HZ 附近）：
   - `CTRL_HZ=250` 保持（**控制环仍 250Hz**，只解耦采样）。
   - 新增：`ENC_SAMPLE_HZ=2000`、`ENC_SAMPLE_PERIOD_US=500`、`ENC_SPI_HZ=8000000`（2MHz→8MHz）、
     `ENC_HIST=16`、`ENC_VEL_WINDOW=8`、`ENC_DIAG_DIV=100`、`ENC_SIGN_FLIP_SAMPLES=ENC_SAMPLE_HZ/12`。
   - 新增共享快照结构 `struct EncShared`（提前声明，规避 .ino 自动原型顺序问题）。
3. **新增高频采样实现**（紧跟 `readAngleCom()` 之后）：
   - 全局：`g_enc_mux`(portMUX)、`g_enc`(EncShared)、`g_enc_timer`、`g_cmd_angle/g_cmd_dia`；
     回调私有状态（`enc_cb_*`、`enc_hist_*` 环形缓冲、EMA/符号锁定）；
     供外部读的 `enc_sample_hz_meas / enc_cpu_pct / enc_loop_hz`。
   - `encReadDiagInline()`：偶发读 DIAAGC（AGC/磁场标志）。
   - `encSampleCb()`：**采样回调**——读 ANGLECOM → 整型解缠累加 counts → 写历史环 →
     窗口差分算 rpm → 尖峰拒绝 → EMA(0.9/0.1) → 符号锁定 → 临界区写快照 + 累计采样耗时。
   - `encGetSnapshot()` / `encTakeBusy()`：loop 侧临界区读快照 / 取并清零 CPU 统计。
   - `encoderBegin()`：预热 SPI → 创建并启动 esp_timer 周期定时器（500µs）。
4. **`setup()`**：SPI `SPISettings(2e6→ENC_SPI_HZ, MODE1)`；预热帧后调用 `encoderBegin()`。
5. **banner**：`enc_sample_hz=2000 (target) … spi_hz=8000000` + 解耦说明行（含 Nyquist~60000RPM）。
6. **命令**：新增 `ENC?`（`ENC`）——打印 `target_hz / meas_hz / cpu% / loop_hz / window / spi_hz / nyquist_rpm / counts / raw / rpm / seq`。
7. **`loop()` 重写**：
   - 不再 `readAngleCom()`；改 `encGetSnapshot()` 取最新值。
   - `motor_unwrapped_counts/deg`、`rpm_signed_stable`、`rpm_filt` 由快照镜像（供 hall/相位/measureHold 沿用）。
   - 本控制拍 `ddeg` 由「解缠累加计数差」得出（高速也不折叠），喂 `phaseTick`。
   - 每 ~500ms 计算 `enc_sample_hz_meas / enc_cpu_pct / enc_loop_hz`。
   - **遥测 CSV 末尾追加 `enc_sample_hz`（第 25 列）**；旧列位置不变，PC/手机解析按前置索引兼容。

### 线程安全

- 单写者（esp_timer 回调）、单读者（250Hz loop）。
- 共享量用 `portMUX_TYPE g_enc_mux` + `portENTER/EXIT_CRITICAL` 复制**整块快照**（含 int64 counts、float rpm），避免撕裂读。
- CPU 统计（busy 累计）同锁内取出并清零。

### 关键参数

| 参数 | 值 | 说明 |
|------|----|------|
| 采样率 | 2000 Hz（周期 500µs） | 实测稳定达标 |
| SPI 时钟 | 8 MHz | AS5047P ≤10MHz |
| 测速窗口 | 8 样本 = 4ms | 量程(解缠)与分辨率解耦 |
| 滤波 | 窗口差分 + EMA 0.9/0.1 | 空载噪声 ±~0.9RPM |
| 符号锁定 | 反向持续 ~83ms 才翻 | 单向高速不乱跳± |
| 控制环 | 250 Hz（未改） | 只解耦采样 |

## 4. 验证结果（COM10，空载，闭环 CLOSED + GainMap ON）

日志与 CSV 见第 6 节。全部**保活 0.5s 重发 RPM**（防 HOST_TIMEOUT 1.5s ESTOP），CSV 每秒 flush。

### 4.1 采样率 / CPU（`ENC?` 实测）

| 工况 | enc_sample_hz | 采样任务 CPU% | 主循环 loop_hz |
|------|---------------|---------------|----------------|
| 空转(停) | **2000.0** | 2.5% | ~97–101k |
| 2000RPM | 2000.0 | 2.8–3.0% | ~67–85k |
| 4000RPM | 2000.0 | 2.5–2.6% | ~70k |
| 6000RPM | 2000.0 | 2.6% | ~68k |

- 采样率**稳定 2000Hz（≥1000 达标）**；CPU 占用极低（~2.5–3%）；主循环仍以数万~十万 Hz 空转，说明 CPU 余量极大。

### 4.2 高转速测速不折叠 + 霍尔盘频交叉核对

霍尔换算电机转速 = `out_hz × 27.744 × 60`。稳态窗口（升速 5s 后）：

| 目标RPM | 编码器均值 | min–max | spread | 霍尔换算RPM | 交叉误差 | 折叠? |
|---------|-----------|---------|--------|-------------|---------|-------|
| 2000 | 2001 | 1934–2054 | 119 | 2001 | **0.0%** | 否 |
| 4000 | 4054 | 4000–4112 | 112 | 4080 | **0.6%** | 否 |
| 6000 | 6037 | 5968–6072 | 105 | 6031 | **0.1%** | 否 |

- 稳态 spread 仅 ~105–120RPM（原 250Hz 在接近/超过 7500 会塌陷折叠）；与霍尔独立测量吻合到 <1%。

### 4.3 越过旧 7500RPM 折叠界（RPMMAX 9000，6000→8000）

| 目标RPM | 编码器均值 | spread | 霍尔换算RPM | 交叉误差 |
|---------|-----------|--------|-------------|---------|
| 6000 | 5831 | 1374* | 6031 | 3.4% |
| 8000（实际达 ~7300） | 7277（max 7471） | 511 | 7301 | **0.3%** |

- 空载下电调/前馈图在 8000 设定处**饱和**，实际稳态到 ~7277–7471RPM；**关键是编码器在跨越 7500 附近仍与霍尔吻合 0.3%，无折叠**。
- （*6000 段 spread 偏大是本次含升速 settling；4.2 专项 6000 段稳态 spread 仅 105。）
- Nyquist@2kHz=60000RPM，测速本身对 12000RPM 完全够用；未达 8000 是**动力/前馈**限制，非测速限制。

### 4.4 CPU 影响小结

- 采样任务（esp_timer）：每样本 SPI 读 ~12–15µs（含偶发诊断帧），占空比 **~2.5–3%**。
- 控制环仍 250Hz，主循环空转 ~7万–10万 Hz，**几乎无额外负担**；解耦后 loop 不再阻塞在 SPI。

## 5. 已知问题 / 未完成 / TODO

1. **8000RPM 未真正达到**（空载 ~7300 饱和）：受电调/前馈图限制，非测速问题。
   如需验证更高转速：在更高 `RPMMAX` 下重跑 `LEARN`/`MEASURE` 扩展前馈图（谨慎分段升速）。
2. **SPI-DMA 未上**：当前同步读已足够轻（~2.5%）。若后续要挤更多余量或提到 >4kHz，可评估 GDMA。
3. **ABI + PCNT**（硬件正交计数，真正零 CPU）：未来可选；需改接线且失去绝对角。
4. **前馈/PID 复核**：控制环仍 250Hz，PID 未受采样解耦影响；但测速现在**更平滑、延迟更低**，
   理论上可重新整定获得更紧的跟踪（可选，非必须）。
5. **遥测新增第 25 列 `enc_sample_hz`**：PC `encoder_monitor.py` / 手机 App 若要显示需读末列（当前按前置索引解析不受影响）。
6. **测试脚本小瑕疵**：`_enc_cross7500.py` 的 `ENC?` 正则把 `nyquist_rpm=60000` 误当 `rpm`（仅显示，固件与 CSV 数据正确）。
7. **符号锁定/EMA 参数**在 2kHz 下按经验设置（flip ~83ms、EMA 0.9/0.1），扑翼周期负载下可再观察是否需调。
