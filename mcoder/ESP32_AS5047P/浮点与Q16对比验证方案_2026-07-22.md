# 浮点 vs Q16.16 对比验证方案

> **日期**：2026-07-22（口径修正：同日晚）  
> **工程**：`mcoder/ESP32_AS5047P`  
> **固件**：`firmware/ESP32ReadAS5047P/`（`USE_FIXED_POINT` / `q16_math.h` / `enc_ring.h` / `Q16_SHADOW_COMPARE`）  
> **架构锁**：采集 **2k** / 使用 **2k** / 输出 **400** / USB 遥测 **20**；**禁用「取用」**  
> **串口**：COM10 @ 921600  

---

## 0. 验收框架（仅两轴 · 主）

| 轴 | 问题 | 方法 | 主脚本 / 命令 |
|----|------|------|----------------|
| **轴1 · 算法正确性** | 计算是否有错 / 有多大量化误差 | **同一 raw** `(t_us, counts)` 同时间戳 → 浮点窗差+EMA **与** Q16.16 窗差+EMA **双算** → 逐点/配对 \|Δrpm\| | `pc/compare_q16_same_sample.py`；板端 `Q16CMP?`（浮点主控 + Q16 影子） |
| **轴2 · 计算占用** | 对系统计算能力占用差多少 | **同架构**下分别测 float 路径 vs `USE_FIXED_POINT=1` 路径的 `enc_busy` / `enc_cpu%` / `LOAD?` / `ctrl_overrun` 等 | `pc/_load_compare.py`；双烧各采 `LOAD?`（或历史 `q16_cmp_*` 中的 LOAD 快照） |

### 明确非主轴（勿作轴1证据）

- **双烧闭环「跟目标 RPM → 比稳态跟踪均值差」**：**不是**算法精度验收。  
- 日志 `pc/logs/q16_cmp_*_20260722_174*` / 旧 `compare_float_q16.py` 阶梯 Δmean≈47：**方法论无效于轴1**（台架/扰动/控制混入）。  
- 该次双烧的 **LOAD / enc_busy** 仍可用于 **轴2**（负载占用与跟踪精度正交）。

## 1. 目标与非目标

### 1.1 目标

1. **轴1**：证明同采样下 Q16 求速+EMA 相对浮点 **无实现错误**，量化误差可控（见 §5.1）。  
2. **轴2**：量化 float vs Q16 在 2k 回调上的 busy/cpu 差（见 §5.2）。  
3. 安全回退：默认浮点、除零/溢出不崩、实时路径无打印；可选确认定点闭环仍可稳 ≥2000（**次要系统检查**，非轴1）。

### 1.2 非目标

- 不把 Q16 设为默认主路；不删浮点。  
- 不做全链路 PID/LS 定点验收（备份仅采集侧求速+EMA）。  
- 不以双烧跟踪静差作为「定点算得准不准」的结论。

## 2. 台架安全约束（硬性）

| 约束 | 要求 |
|------|------|
| 架构 | 采集/使用 2000Hz，输出 400Hz；禁止改成 1200；术语禁用「取用」 |
| 有效工况（若转电机） | ≥2000 RPM |
| 保活 / 停转 | HOST OFF 或保活；FAIL→ESTOP / PWM 1000 |
| 实时路径 | 2k 回调 / 400 输出内 **禁止** Serial / 阻塞 hostPrintf |
| 默认回退 | `#define USE_FIXED_POINT 0`；影子对比 `Q16_SHADOW_COMPARE` 可开，控制权威仍为浮点 |
| 轴2 测 busy | **不要**用「浮点+影子双算」当 float 基线（影子会抬高 busy）；float 基线需 `Q16_SHADOW_COMPARE=0` 或历史无影子会话 |

## 3. 固件开关与查询

| 项 | 说明 |
|----|------|
| `USE_FIXED_POINT` | `0`=浮点主路（默认）；`1`=Q16 求速写共享 RPM（轴2 定点侧） |
| `Q16_SHADOW_COMPARE` | 浮点主路时默认 `1`：同窗再算 Q16，只累积 \|Δ\|；`Q16CMP?` / `Q16CMP RESET` |
| `FIXED?` | `use_fixed_point=` / `shadow_q16=` |
| `LOAD?` / `LOAD RESET` | 轴2 负载快照 |
| `ENC?` / `CTRL?` | 自检 meas_hz≈2000、out_hz=400、usb_telem_hz=20 |

## 4. 轴1 方法（同采样双算 · 主）

推荐顺序：

```text
A) PC 离线：合成或 CSV (t_us,counts) → compare_q16_same_sample.py --synthetic|--csv
B) 板端：浮点控制 + Q16 影子 → 转电机 ≥2000 → Q16CMP RESET → dwell → Q16CMP?
   （脚本：compare_q16_same_sample.py --hw）
```

**禁止**用「flash float 跟目标；再 flash Q16 跟同一目标；比 Δmean」作为轴1 PASS/FAIL。

窗长 / α 与固件一致：`ENC_VEL_WINDOW=8`，EMA α=0.10，CPR=16384。

---

## 5. 通过 / 失败标准

### 5.1 轴1 · 算法正确性

| 指标 | PASS | FAIL |
|------|------|------|
| 同采样 mean\|Δrpm\| | **&lt; 0.5 RPM** | ≥ 0.5（疑实现差或量化异常大） |
| 同采样 max\|Δrpm\| | **&lt; 2 RPM**（尖刺容差） | ≥ 2 且持续 |
| 符号/窗/限幅 | 两侧行为一致、无 NaN/疯转 | 一侧发散 |

> 旧文「双烧稳态跟踪均值差 &lt;0.5」**已降级**：可作次要系统检查，**不是**轴1 主判据。

### 5.2 轴2 · 计算占用

| 指标 | 关注 | 说明 |
|------|------|------|
| `enc_busy_avg_us` / `enc_busy_max_us` | float vs Q16 差值 | 主占用差 |
| `enc_cpu%`（≈ busy×meas_hz/10000） | 同左 | 相对 2k 周期 500µs 仍应远低于饱和 |
| `ctrl_period_*` / `ctrl_overrun` | 输出节拍健康 | 期望 overrun 增量≈0 |
| `loop_hz` / `async_log_drop` | 辅 | 遥测/空闲影响，与定点正交时控制变量 |

轴2 **无**「必须比浮点更省」硬阈值；结案写清数值与是否可接受。

### 5.3 安全门（两轴共用）

除零/溢出有界、默认浮点、双路径可编译、实时无打印 → 见原清单。`enc_ring_overrun` 在无独立 consumer 时可持续累加 → 文档化为计数语义，勿与 `ctrl_overrun` 混淆。

### 5.4 结案标签

| 标签 | 条件 |
|------|------|
| **轴1 PASS** | §5.1 同采样判据过 |
| **轴2 已量化** | 两侧 LOAD/busy 有数且架构自检 OK |
| **Q16 可作备份启用** | 轴1 PASS + 安全门 + 轴2 占用可接受 |
| **精度不够** | 仅当 **同采样** mean\|Δ\|≥0.5 → 修算法；**不是**旧双烧跟踪 FAIL |

## 7. 安全验证清单（摘要）

- [ ] `q16_div` / `calc_rpm_window_q16` 除零有界

- [ ] 回调内无 Serial/hostPrintf

- [ ] 双路径 compile OK  
- [ ] 轴1：同采样脚本或 `Q16CMP?` 有 PASS 日志

## 10. 实机结果摘要

### 10.1 轴1（同采样双算）

| 轮次 | 方法 | 结果 | 日志 |
|------|------|------|------|
| 合成 17:57 | `compare_q16_same_sample.py --synthetic` | mean\|Δ\|≤**0.00079**；max\|Δ\|≤**0.095** → **PASS** | `pc/logs/q16_same_sample_synth_20260722_175754.*` |
| 板端 18:07 | 浮点主控 + Q16 影子；`Q16CMP?` @2000/3000/4000 | mean\|Δ\|≤**0.00123**；max\|Δ\|≤**0.00342** → **PASS** | `pc/logs/q16_same_sample_hw_20260722_180700.*` |
| 板端 18:04（作废） | 误用 `Q16CMP RESET` 清零影子 EMA | 假尖刺 max~1800–3600；**已修**：RESET 仅清统计 | `…_hw_20260722_180405.*`（勿作结案） |

> 旧双烧跟踪 Δmean≈47 @3000：**不作轴1 结论**。

### 10.2 轴2（计算占用 · 同架构 2k/2k/400）

| 侧 | enc_busy_avg | 备注 |
|----|--------------|------|
| float 纯路径（17:42，无影子） | ≈**10.2 µs** | ctrl_overrun=0 |
| Q16 主路径 `USE_FIXED_POINT=1`（17:47） | ≈**12.6–12.9 µs** | 约 **+2.4–2.7 µs**；ctrl_overrun=0 |
| float+影子（18:00 停转，仅参考） | ≈**13.1 µs** | 双算抬高 busy，**不作 float 基线** |

日志（轴2）：`pc/logs/q16_cmp_float_20260722_174221.*`、`q16_cmp_q16_20260722_174500.*`。

### 10.3 结案

- **轴1 PASS**：实现正确，量化误差 ~0.001 RPM 量级。  
- **轴2 已量化**：Q16 回调约贵 ~2.5 µs @2k（相对 500 µs 周期可忽略）。  
- 默认 `USE_FIXED_POINT=0`；影子对比可开；**不**以旧跟踪 Δ47 否定定点。
