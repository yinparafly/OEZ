# 板内 TEST（最小通讯）

台架分段测试写死在 ESP32 状态机；主机只发开始/停止，判定不依赖 PC `motor_spin_detect`。

## 命令

| 主机 → 板 | 说明 |
|-----------|------|
| `TEST START smoke2000` | 冒烟 2000 |
| `TEST START step7500` | 门闩 2000 + 7500×20s |
| `TEST START idle` | 确认静止 |
| `TEST STOP` | 中止 |
| `TEST?` | 查状态 |

板 → 主机（一行摘要即可）:

```text
# TEST DONE name=smoke2000 ok=1 enc_rpm=1995 target=2000 pulse=1320 err=40 hall_d=18 sat=0 reason=hold_ok
# TEST OK name=smoke2000 enc_rpm=1995
```

失败时 `ok=0`，并有 `# TEST FAIL name=… reason=…`。

## 固件判定（常量可调）

- **在转**：观察窗 ~3s，\|rpm\| 中位或均值 &gt; 90，且 \|rpm\|&gt;阈占比 ≥70%；霍尔 irq Δ≥1 记 `hall_ok`（辅），编码器过即可判电机轴在转。
- **smoke2000**：判转 PASS 后稳 ~12s；结束 mean 相对 2000 误差 &lt;15%（或绝对下限）→ OK。
- **step7500**：先内嵌 smoke 门闩；7500 稳 20s；误差阈 + 无 ESTOP；`sat=` 记脉宽饱和但不单独 FAIL。
- **TEST 运行中**：禁用 `HOST_TIMEOUT` ESTOP（与 FLIGHT 类似）；结束恢复。
- 实时路径仍禁打印；TEST 状态行走异步日志。
