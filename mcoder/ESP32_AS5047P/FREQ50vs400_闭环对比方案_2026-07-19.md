# FREQ 50 Hz vs 400 Hz：闭环控制效果对比实验

**目的**：在**同一控制参数、同一会话**下，专门回答——提高 ESC PWM 载波到 400 Hz，跟踪/响应是否比 50 Hz **更好**（还是仅「够用、少夹断」）。

**原则**：只改 `FREQ`；一步回答一类指标；结案用量化阈值，不凭体感。

---

## 1. 固定条件（禁止本轮拧参）

```text
协议 PWM，ADG OFF，GAIN ON，PROFILE noload
SOFT UP/DOWN = 800 / 300
Ka = 0.05
ctrl_hz = 250（速度环周期不变）
入带 ±10%，settle = 8 s
试转从 ≥1000 RPM
```

唯一自变量：`FREQ ∈ {50, 400}`。

安全：任一侧 FAIL/ABORT → `FREQ 50` + 1000 μs 停；报告仍写出已测侧。

---

## 2. 要回答的问题

| ID | 问题 | 主要指标 |
|----|------|----------|
| **Q1** | 阶梯跟踪谁更快入带？ | 各点 `t_band`、末段稳态误差 |
| **Q2** | 升/降动态谁更跟斜坡？ | A1/A2 `t_band`、超调 % |
| **Q3** | 多段「曲线」谁更贴？ | 段末误差、过渡峰值超调、全程是否 FAIL |

说明：速度环仍是 250 Hz；本实验测的是**执行器刷新**对闭环表现的边际效应，不是把控制带宽提到 400 Hz。

---

## 3. 实验块（同顺序跑完两侧）

默认顺序：**先 50 → 再 400**（可用脚本 `--order 400,50` 换序做一次复验，排除温升顺序偏差）。

### C1 — 阶梯（答 Q1）

测点：`1000 → 2000 → 3000 → 4000 → 5000 → 6000`  
每点：斜坡到位 → settle 8 s → 记 `t_band` / 末段 mean / peak / pulse → 点间停转。

### C2 — 加减速（答 Q2）

| 名 | 轨迹 | 斜坡 |
|----|------|------|
| A1 | 1000 → 2000 | UP/DOWN 800/300 |
| A2 | 3000 → 2000 | 同上 |

### C3 — 多段曲线（答 Q3）

模拟「跟控制曲线」的简化折线（非任意波形发生器）：

```text
1000 → 2000 → 4000 → 2000 → 1000
```

每段 settle 6 s（可调）；段间**不停转**，连续跟指令。  
指标：每段末 1 s 均值误差、段内峰值相对目标的超调、全程 PASS/FAIL。

---

## 4. 判读规则（结案用语）

对每个指标定义 Δ = 值(400) − 值(50)（时间类：负=400 更快）。

| 结论标签 | 条件（建议） |
|----------|----------------|
| **400 明显更好** | C1：≥4/6 点 `t_band` 缩短 ≥0.15 s **且** 稳态误差不恶化；C2：A1+A2 均不恶化，至少一项缩短 ≥0.15 s |
| **相当 / 噪声内** | 多数 \|Δt_band\| &lt; 0.15 s，误差/超调同量级 |
| **400 更差** | 多点变慢 ≥0.15 s，或超调/稳态明显变差，或一侧 FAIL |
| **仅执行器优势** | 跟踪相当，但 400 高油门脉宽余量更大（已知夹断论证）→ 工作默认仍可维持 400 |

禁止仅因「400 也 PASS」写成「跟踪更好」。

## 7. 实测结案（2026-07-19 12:57，顺序 50→400）

报告：`FREQ50vs400对比报告_20260719_125723.md`

| 块 | 结果 |
|----|------|
| C1 | 6/6 点 \|Δt\|&lt;0.15 s（最大约 −0.12 s @3000）→ **噪声内** |
| C2 | A1/A2 相当；400 超调略低（非显著差异） |
| C3 | 升段相当；**4000→2000 两侧均 FAIL_BAND**（降速段 settle/斜坡共同问题，非 FREQ 差异） |

**结案标签：相当 / 噪声内** — 未证明 400 跟踪系统性更好；工作默认仍维持 **FREQ=400**（脉宽余量），50=安全回退。
