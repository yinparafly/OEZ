# 扑翼盘相位停机（HOLD PHASE）· 2026-07-22

> 软件架构 / 选圈 / 保证边界 / 日志结论：见 [`相位停机软件设计_2026-07-22.md`](相位停机软件设计_2026-07-22.md)。  
> 本文侧重操作 API 与调参。架构锁：浮点 · 采集+使用 2k · 输出 400；禁「取用」；不切 Q16 主路。

## 传感模型（钉死）

> **互质齿重锁**：质数/互质齿轮(12×14 / 59×79) → 磁编绝对零相对霍尔零每圈漂移，必须每次霍尔沿重锁 disc_ref + motor_counts，禁止一次性首锁永用。

传感模型详解见：[`相位与磁编换算说明_2026-07-23.md`](相位与磁编换算说明_2026-07-23.md)（互质齿每沿重锁；Δmotor=堆叠 counts，非单圈 raw）。

**磁编码器是连续传感器；霍尔是稀疏绝对标记。**

过霍尔后，盘相位只靠电机磁编推算，直到下一次霍尔沿再复位：

```text
GPIO4 沿 → latch disc_ref = 0°   , motor_counts_at_hall   // 霍尔 = 清零
GPIO5 沿 → latch disc_ref = 180° , motor_counts_at_hall

disc_phase = wrap360(
    disc_ref
  + esc_sense * (motor_counts − motor_counts_at_hall) / CPR * 360° / gear
)

选圈（单向前向）:
  motor_revs = gear × wrap360(target − disc) / 360
             (+ k×gear 若制动距离需多整盘圈)
  // 1 盘转 ↔ ≈27.744 电机转 = 4661/168
```

| 符号 | 含义 |
|------|------|
| `CPR` | AS5047P = 16384 |
| `gear` | **4661/168**（小齿 12·14，大齿 59·79）= (59/12)×(79/14) ≈ **27.7440476** |
| `esc_sense` | +1 / −1：使盘角随油门驱动方向递增（修旧版无符号导致的 ~180° 错位） |

`HALL CAL` = 把**当前姿**标为物理 **0°**（应在 GPIO4 下扑点执行，不是任意位置）。

## 相位定义

| 盘相位 | 传感器 / 来源 | 说明 |
|--------|----------------|------|
| **0°** | **GPIO4** 霍尔（下扑） | 绝对复位 `disc_ref=0`；之后编码器推算 |
| **180°** | **GPIO5** 霍尔（上举） | 绝对复位 `disc_ref=180`（纠正仅靠 0° 零点时的漂移/错位） |
| **90° / 任意** | 编码器合成 | `disc_phase` 上取目标；无专用霍尔 |

电机 **单向**（`esc_sense`）。提前制动用 **编码器盘相位**（目标前 lead），**不是**「等霍尔再停」。霍尔：复位估计 + 到位确认。

**曾出现的问题**：指令停 0° 却落在物理 ~180° —— 旧式只在 GPIO4 置零、无 `esc_sense`、盘剩余角误用电机 `uniTravelDeg`，零点/符号错就把「固件 0°」标到了物理半圈。现模型：GPIO5 也绝对锁存；盘剩余角 = `wrap(target−disc)`。

## 提前制动（核心）

**禁止**「等霍尔沿再切油」作为**首次**接近策略——惯量会冲过目标。  
**允许**首停 miss 后以**极低速 REFINE** 爬到目标霍尔再停（冲量小，霍尔作绝对 latch）。  
**禁止**在 BRAKE/SETTLE 用位置误差加大油门（单向 ESC 无主动刹，只会冲过）。

流程（2026-07-23 起 = **在线速度规划**；朋友建议见 [`相位停机朋友建议_2026-07-23.md`](相位停机朋友建议_2026-07-23.md)）：

1. **APPROACH**：可选 `stop_ms` 软降仅作高速**斜坡限幅**；之后按剩余盘角规划  
   `desired_rpm = (remain/tc)·(gear/6)`（夹 `[40, crawl]`），**CLOSED** 跟踪。  
2. **BRAKE**：`remain ≤ max(est_brake + tol, lead_eff)` 时立刻 PWM=1000µs。  
   - `est_brake ≈ k·rpm²`（Scheme B；成功停后 EMA 学 `k`）  
   - 旧 `lead_eff` 作安全二次触发  
3. **SETTLE**：等电机 RPM 跌到阈值（无误差→油门）。  
   - 带内且（非 0/180、或已有 `hall_confirm`、或 `PHASE REFINE OFF`）→ `DONE`。  
   - **0°/180°** 且 `PHASE REFINE ON`：若 `|err| > tol` **或** 无 `hall_confirm` → 进入 **REFINE**。  
4. **REFINE**（仅 0/180）：极低速单向爬行，等到 **GPIO4（0°）或 GPIO5（180°）** 沿 → 立刻 1000µs → 短停 → `DONE reason=refine_hall`。  
5. 爬行盘角 &gt;≈1 转 / 总超时 → `ESTOP`。

**90°**：无专用霍尔 → **不**做 refine-to-Hall；仅编码器带判定（`tol`）。

```text
est_brake = clamp(k * rpm_motor², 2°, 80°)
lead_eff  = lead_deg + ω_disc × (lead_ms/1000) + lead_rpm_k × |rpm|
cut       = max(est_brake + tol, lead_eff)
remain    = wrap360(target − disc)
```

| 参数 | 默认 | NVS | 含义 |
|------|------|-----|------|
| `brake_k` | 0.0008 | `hpbk` | 滑行盘° ≈ k·rpm² |
| `plan_tc` | 1.5 | `hptc` | 规划时间常数 s |
| `lead_deg` | 10 | `hplead` | 旧基础提前（安全二次） |
| `lead_ms` | 100 | `hpleadt` | 旧时间项 |
| `lead_rpm_k` | 0.03 | `hpleadk` | 旧 RPM 项 |
| `tol` | 5 | —（RAM） | 到位带 + 切油 margin；`PHASE TOL` |
| `refine` | ON | —（RAM） | 首停后霍尔二次对准；`PHASE REFINE` |

霍尔角色：**复位估计 + 确认 / 诊断 + REFINE 绝对对准**。接近段才碰到 GPIO4/5 → `hall_*_before_plan`（应增大 `brake_k` / 减小爬行上限）。

## 串口 API

```text
HOST OFF
HALL?                    # cal=1、disc_ref、gear=4661/168、传感模型一行
PHASE LEAD?              # 读旧提前量（安全二次触发）
PHASE LEAD 12 120 0.04   # 设 deg / ms / k（RAM）
PHASE LEAD SAVE          # 写入 NVS（含 hpbk/hptc）

PHASE PLAN?              # brake_k / plan_tc / est_brake / desired_rpm
PHASE PLAN TC 1.5        # 规划时间常数 s（RAM；SAVE 见 BRAKEK）
PHASE BRAKEK?            # 读 k 与当前 est
PHASE BRAKEK 0.0008      # 设 k（RAM）
PHASE BRAKEK SAVE        # k + plan_tc → NVS hpbk/hptc

PHASE REFINE ON|OFF|?    # 0/180 首停后是否霍尔二次对准（默认 ON）
PHASE TOL 5              # 到位容差盘°（默认 5；兼 plan margin）
PHASE TOL?

HOLD PHASE 0             # 停到盘 0°（编码器相位；GPIO4 确认 / refine）
HOLD PHASE 90 100        # 停到 90°，规划 RPM 上限 ~100（无霍尔 refine）
HOLD PHASE 180
PHASE 0 | PHASE 90 | PHASE 180   # 简写（等同 HOLD PHASE）
PHASE HOLD 90            # 同义

PHASE?                   # disc / state / err / tol / est_brake / desired_rpm / brake_k …
HALL CAL                 # 当前姿=物理 0°（须在 GPIO4）
ESTOP / STOP             # 中止
```

成功：`# ACK HOLD PHASE DONE reason=settle_*|refine_hall … brake_k=…`  
切油：`# HOLD PHASE BRAKE reason=est_brake|lead_fallback|hall_*_before_plan|refine_hall_*`  
失败：`# ESTOP hold_phase_timeout|miss|coast|refine_max` → 油门 1000µs。

`PHASE?` 关键字段：`state=APPROACH|BRAKE|SETTLE|REFINE`、`est_brake`、`desired_rpm`、`brake_k`、`plan_tc`、`hall_confirm`、`refine`。

## 调参建议

1. 先看 `PHASE PLAN?`：低爬行 `HOLD PHASE 0 80`，观察 BRAKE `reason=est_brake` 与 DONE `err`。  
2. 常 `hall_*_before_plan` 或过冲 → **加大** `PHASE BRAKEK`（或等几次 DONE 让 EMA 学大）。  
3. 总停在目标前很多（欠冲）→ **减小** `brake_k`，或略减 `PHASE LEAD`。  
4. 接近段过猛/过钝 → `PHASE PLAN TC 1.2`～`2.0`。  
5. 满意后 `PHASE BRAKEK SAVE`（或 `PHASE LEAD SAVE`）。  
6. 台架长测用 `HOST OFF`；HOLD PHASE 段内已豁免主机超时。  
7. 看 `# HALL UP … disc_before=`：若刚过 GPIO5 时 `disc_before≈0` 而非 ≈180，说明此前零点/符号仍偏，以本次 180° latch 为准。

```powershell
cd E:\OEZCON\mcoder\ESP32_AS5047P\pc

python hold_phase_learn.py --port COM10 --iters 4 --rpm 5000 --stop-ms 2000 --tol 10
```

流程：每次 `HOLD PHASE` 后读 `disc−target`（wrap180）→ 调 `PHASE LEAD`；若停在固件 0° 后盘行程 &lt;50° 即遇 GPIO5，则 `PHASE OFFSET += 180`。结束 `PHASE LEAD SAVE`（NVS：`hplead*` + `hphoff`）。

**硬前提**：至少一侧霍尔有沿。GPIO4 全程无沿时，只能相对 GPIO5=180° latch；物理 0° 无法霍尔确认。

## 限制

- 低速爬行专门用于相位停，**不是** ≥2000 RPM 连续工况。  
- **90°** 精度取决于减速比与最近一次霍尔 latch；两霍尔之间靠磁编；**无 refine-to-Hall**。  
- **0°/180°**：首停后可由 REFINE 爬到对应霍尔，把盘相位绝对 latch 到 GPIO4/5。  
- 空载与接扑翼惯量不同，提前量需分别调。  
- 与电机轴指令 `GOTO` / `STOPAT` / `PHASE ZERO`（电机相对角）不同：本功能是 **输出盘** 相位。
