## 1. 背景与目标

- **负载变更后的复核链条**：负载改变后，先**核对电机转速计算是否正确** → 再**接扑翼输出盘霍尔做独立交叉验证** → 最后**把测速能力拓到高转速**。
- **扑翼机工况约束**：扑翼机在 **2000RPM 以下无实际意义**（低速顿挫、无有效气动做功），因此有效工作区间在 2000RPM 以上；测试与整定都聚焦中高速段。
- **转速上限放开**：目标转速上限（`RPMMAX`）与硬上限（`MOTOR_RPM_ABS_MAX`）已放开到 **12000RPM**，为高转速测速与后续扩展留出量程。
- **核心矛盾（起点）**：测速原来跑在 250Hz 控制环里，Nyquist 仅 7500RPM，**物理上测不了更高转速**（超过即折叠）。这是本轮改造的直接动因。

## 2. 今日已完成（结论 + 证据）

### 2.1 转速计算正确性（第 1 步，负载变更后复核）

- **结论**：转速公式正确。编码器滤波转速与展开角窗口转速一致（无霍尔时 |unwrap-enc|/enc ≤ 2.0%），接霍尔后交叉验证进一步坐实。
- **证据**：`pc/logs/rpm_check_20260721_165919.md`（PWM1200/1300/1400 三档 PASS_INTERNAL，unwrap-enc 偏差 0.8/2.0/1.0%）。

### 2.2 霍尔定点减速比 ≈ 设计值（关键交叉验证）

- **结论**：合并（0°下扑 + 180°上举）**定点减速比实测 = 27.743994**，设计值 = **27.744048**（`(59×79)/(12×14)=4661/168=27.7440476`），偏差 **-0.0002%**，几乎完美吻合 → 证明测速链路（编码器计数→转速→与霍尔输出频率换算）正确。
- **"27.742 不是打印截断"已明确定案**：3 位显示的 27.742 是对同一个真实、准确的定点结果的更粗略呈现；6 位定点算法（整型累加 int64、每圈 16384、8192 环绕解缠、`%lld.%06lld` 打印，不走浮点截断）给出的稳定值就是 ~27.74x，合并中位数 27.737305（vs 设计 -0.0243%）。与设计比的 0.01%/0.1% 量级偏差来自角度重复性/齿隙/偶发双沿，**不是打印位数问题**。
- **证据**：`ff_pid_对比_20260721_182909.md`（第五节"关键：定点减速比精度"）；相关采样 `hall_gear_samples_*_20260721_*.csv`。

### 2.3 霍尔根因定位与修复（漏沿问题）

- **根因**：霍尔读数顶在低电平出不来——**固件内部上拉把引脚顶住低电平**；去掉内部上拉后恢复正常。触发电平以厂商 51 样例为准 = **低有效（ACTIVE LOW）**，并加双采样消抖。
- **漏沿修复**：原轮询方式会**漏掉边沿** → 改为**中断（gpio_isr / ANYEDGE + 软件确认）**采两路霍尔。
- **接线要点**：霍尔 VCC=**5V**、共地、DO 为开关量须**分压到 3.3V** 再进 GPIO4/5；电调信号仍 GPIO9；GPIO4/5 不占 USB。
- **证据**：`工作日志_2026-07-21.md`、`扑翼霍尔接线_2026-07-21.md`；`_hall_irq_*.py` 系列脚本与 `hall_irq_*_20260721_*.txt` 日志。

### 2.4 前馈图重建 + PID 重整定 + 分区增益（负载变更后重学）

- **前馈图重建**：旧前馈图对当前台架**偏高 7%–16%**（同一 pulse 转得更快），导致闭环里 PID 长期补 ~90–110µs、超调大。**重跑 LEARN 得到新前馈图**后，同目标 RPM 的前馈 pulse 整体下调（见下表），超调从 **~30% 降到 ≤2.3%**。

  | 目标 RPM | 旧 pulse(µs) | 新 pulse(µs) | 差(µs) | 变化% |
  |---:|---:|---:|---:|---:|
  | 2000 | 1234 | 1149 | -85 | -6.9% |
  | 3000 | 1351 | 1219 | -132 | -9.7% |
  | 4000 | 1462 | 1294 | -168 | -11.5% |
  | 6000 | 1694 | 1427 | -267 | -15.8% |

- **全局 PID 重整定**：`kp 0.08 → 0.0248`、`ki 0.25 → 0.0621`（kd=0）。
- **分区增益 GainMap（12 点）已 SAVE**，`schedule=ON`、`valid=1`（0→5638RPM 分区，kp/ki 逐区）。
- **KA（加速度前馈）/ ADG（自适应增益）不动**：KA=0（SOFT 斜坡足够平滑）、ADG OFF。
- **闭环验证（新参数）**：2000/3000/4000/6000RPM 稳态 **超调全部 ≤2.3%**、静差 <0.05%、整定时间 1–2.4s，PID 余量 u 仅 -1~-5µs（说明前馈已准确、PID 只做微修）。
- **证据**：`ff_eval_verify_20260721_182431.json`（各档 overshoot 1.73/2.3/1.55/1.07%、static_err_pct ≈0）、`ff_pid_对比_20260721_182909.md`、`learn_relearn_20260721_181947.csv`。

### 2.5 编码器高频采样改造（250Hz → 2kHz 解耦）· 本轮主线成果

- **做法**：编码器角度采样/测速用 **esp_timer 周期回调（500µs=2kHz）内同步 SPI 读**，与 250Hz 控制环**解耦**；控制环仍 250Hz，只取最新快照。SPI 时钟 **2MHz→8MHz**。
- **不折叠原理**：解缠在高频侧完成——每 500µs 读 raw，整型差分（±8192 环绕）累加到 **int64 counts**；测速用"已解缠累加计数"做 8 样本（4ms）窗口差分。解缠 Nyquist 由采样率决定 = **60000RPM**，长窗口差分不再引入折叠，兼得高量程 + 高分辨率。
- **线程安全**：单写者（回调）/单读者（loop），共享量用 **portMUX 临界区整块快照复制**（含 int64 counts、float rpm），避免撕裂读。
- **性能**：实测 **enc_sample_hz=2000** 稳定；采样任务 **CPU ≈2.5–3%**；主循环空转 ~7万–10万 Hz（余量极大）。
- **高转速核对**：2000/4000/6000RPM 稳态与霍尔盘频交叉误差 **0.0 / 0.6 / 0.1%**；并越过旧 7500RPM 折叠界（实测到 ~7300RPM 仍与霍尔吻合 0.3%）。
- **仅改一个固件文件**：`firmware/ESP32ReadAS5047P/ESP32ReadAS5047P.ino`（编译 exit 0，已烧录 COM10）。新增 `ENC?` 命令、遥测 CSV 追加第 25 列 `enc_sample_hz`。
- **证据**：`高频采样改造_2026-07-21.md`（完整背景/选型/改动清单/验证/TODO）、`pc/logs/enc_highrate_20260721_190249.txt`+`.csv`、`enc_cross7500_20260721_190441.txt`。

## 3. 当前限制 / 风险

1. **空载 ~7300RPM 撞动力/前馈饱和**：设定 8000RPM 时空载实际稳态仅 ~7277–7471RPM，因电调/前馈图在该设定处**饱和**。这是**动力/前馈上限，不是测速上限**（测速 Nyquist@2kHz=60000RPM，对 12000RPM 完全够用）。
2. **PID 仍在 250Hz、未在高采样率下重整定**：测速解耦后更平滑、延迟更低，理论上可重整获得更紧跟踪，但目前 PID 未受影响也未重做（非阻塞项，可选）。当前 GainMap 分区只覆盖到 5638RPM，更高段尚未整定。
3. **DMA / ABI+PCNT 未上**：当前同步 SPI 读已足够轻（~2.5% CPU）。SPI-GDMA、硬件 ABI+PCNT 正交计数（真正零 CPU）均为未来可选增强，暂无必要。
4. **符号锁定/EMA 参数为经验值**：在 2kHz 下按 flip ~83ms、EMA 0.9/0.1 设置，扑翼周期性负载下需再观察是否要调。
5. **前馈图为空载所学**：接扑翼机构后**必须重学**（noload 表不可直接搬到 flap）。
6. **测试脚本小瑕疵**：`_enc_cross7500.py` 的 `ENC?` 正则会把 `nyquist_rpm=60000` 误当 `rpm`（仅显示问题，固件与 CSV 数据正确）。

## 4. 后续分步骤计划（TODO）

> 优先级：**P0 立即** / **P1 近期** / **P2 可选**。每项含验收标准。

### P0-1 高速阶梯测试（>7000RPM，判定动力上限）

- **做法**：闭环 + GainMap ON，从 >7000RPM 起，每 **+500RPM** 稳定 **20s**，逐台阶上探。全程 **0.5s 保活重发 RPM**（防 HOST_TIMEOUT 1.5s ESTOP），CSV 每秒 flush。
- **如何判断是否撞动力/前馈上限**（满足任一即判为"到顶"）：
  - 目标每 +500 但**稳态均值不再上升**（增量 <~100RPM）；
  - PID 输出 **u 持续贴上限**（pulse 接近 2000µs 或 `saturated=true`）；
  - `settle_pulse ≈ ff_pulse` 且已接近 2000µs；
  - 编码器与霍尔换算仍吻合（说明不是测速问题，而是动力问题）。
- **验收**：给出"空载可达最高稳态 RPM"及到顶原因（动力 vs 前馈饱和）的明确结论 + 报告路径。
- **安全**：单 COM 锁；FAIL→FREQ 50 + 1000µs；空载标注；≥2000RPM 运行、避免长时间低速顿挫。

### P0-2 若要突破 ~7300RPM 上限

- **路线 A（先试）**：在更高 `RPMMAX` 下**重跑 LEARN/MEASURE 扩展前馈图**到更高段（谨慎分段升速），把前馈饱和点上移。
- **路线 B**：评估**电池/电调动力余量**（电压、电调档位、KV），若确为动力硬上限，则记录并作为空载天花板。
- **验收**：明确是"前馈图不够"还是"动力硬上限"，并落地对应改动或结论。

### P1-1 高采样率下 PID 复核/重整定

- **做法**：利用解耦后更低延迟的测速，对中高速段（尤其 >5638RPM 未覆盖区）复核并按需重整定 GainMap；关注超调、静差、抗扰。
- **验收**：目标工作区间超调 ≤~3%、静差 <~0.5%，且高速段有 GainMap 分区覆盖。

### P1-2 参数固化

- **做法**：把本轮新参数固化并写清默认值：`RPMMAX`/`MOTOR_RPM_ABS_MAX=12000`、`ENC_SAMPLE_HZ=2000`、`ENC_SPI_HZ=8000000`、`ENC_VEL_WINDOW=8`、`ENC_SIGN_FLIP_SAMPLES`、新前馈图 + PID + GainMap（已 SAVE）。
- **验收**：固件启动 banner 与 `ENC?`/`PID?`/`GAIN?` 输出与文档记录一致；文档索引齐全。

### P2-1 可选增强（按需）

- **SPI-DMA（GDMA）**：仅当要挤更多 CPU 余量或采样率提到 >4kHz 时评估。
- **ABI → PCNT**：硬件正交计数、真正零 CPU；需改接线（+3 线）且失去绝对角。
- **迁移 MT6835 磁编码**：更高分辨率；接口为 **SPI 连读 0x1010**（角度寄存器块）。资料见 `MT6835 磁编码资料/`。

### P2-2 扑翼相关（承接上午待办）

- 接扑翼后 flap profile **重学**（前馈 + GainMap）；上举霍尔相对 0° 安装偏角校准；扑翼台架 T3b（平均稳 vs 相位纹波）。

## 6. 复现 / 接手指引

### 6.1 怎么连板

1. 确认板已上电、ESC 已解锁（上电即 1000µs 最低油门），台架空载已固定/卸桨。
2. **单占 COM10**：不要同时开多个占串口的程序（用 `com_port_guard.py` 锁）；确认无残留 python 进程。
3. Python 端务必 `PYTHONIOENCODING=utf-8`（防中文/emoji 乱码）。
4. 自检：先跑 `_enc_idle_check.py` 确认 banner 显示 `enc_sample_hz=2000`、`ENC?` 可用、遥测 25 列。

### 6.2 安全跑高速测试（务必遵守）

- **保活**：跑测时**每 0.5s 重发一次 RPM**，避免 HOST_TIMEOUT（1.5s）触发 ESTOP。
- **RPMMAX**：先按目标设 `RPMMAX`（≤12000）；分段升速，每档稳定 20s 再上探 +500。
- **≥2000RPM 运行**：扑翼工况 2000RPM 以下无意义；且**避免长时间低速顿挫**（低速抖动、无有效工况）。
- **失败回退**：任何异常 → `ESTOP` / `RPM 0` / `PWM 1000`，必要时 FREQ 50 + 1000µs。
- **判定动力上限**：见 §4 P0-1（均值不再升、u 贴上限、pulse 近 2000µs、编码器仍与霍尔吻合）。
- **收尾**：测试后 `_enc_safecheck.py` 确认电机停（pulse=1000、rpm≈0）、释放 COM 锁、退出所有 python 进程。

### 6.3 复现命令（示例）
