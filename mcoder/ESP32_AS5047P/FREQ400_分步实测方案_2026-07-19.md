# FREQ=400 Hz：疑问 → 验证实验 → 最终实验

**日期**：2026-07-19  
**原则**：有疑问先设计**小实验**证伪/证实，再做最终全量程；一步只回答一个问题。  
**固定（验证阶段不拧）**：SOFT 800/300、Ka=0.05、ADG OFF、noload map/GainMap、`ctrl_hz=250`。  
**安全**：任一步 FAIL → `FREQ 50` + 1000 μs，停止更高步。

自动化：`pc/auto_freq400_staged.py`

```text
python auto_freq400_staged.py --port COM10 --phase V1
python auto_freq400_staged.py --port COM10 --upto V3
python auto_freq400_staged.py --port COM10 --phase F      # 仅当 V1–V5 已 PASS
```

## 1. 疑问清单（针对 400 Hz）

| ID | 疑问 | 若不验证就做最终实验的风险 |
|----|------|----------------------------|
| **Q1** | 400 Hz 是否稳定响应油门？（扫频会否偶然） | 闭环全挂却以为是 PID |
| **Q2** | 同脉宽下 RPM 是否≈50 Hz？map 能否不重学？ | 各点稳态偏一截，误调 Ki |
| **Q3** | 400 Hz 下闭环 **1000** 能否入带？ | 低点死区/模式问题被高转速掩盖 |
| **Q4** | 中高点（2k–6k）是否随转速变差？ | 一次跑到 6000 失败无法定位 |
| **Q5** | 升/降动态是否明显差于 50 Hz 经验？ | 误开 ADG 或猛改 Ka |
| **Q6** | 为何工作点选 400 而不是 600？ | 高油门夹断导致「到不了 6000」 |

Q6 可用**计算+已有扫频**回答，不必单独给油：  
600 Hz 周期≈1667 μs &lt; 曾用脉宽~1694 → 夹断；400 Hz 周期=2500 μs → 够用。

## 2. 验证实验（逐步，回答疑问）

### V1 — 回答 Q1（执行器）

| 项 | 内容 |
|----|------|
| 做法 | `FREQ 400`，MEASURE 开环 **1100 μs × 3 s**，停 |
| PASS | \|rpm\| peak≥40，均值大致数百转 |
| FAIL | 不转 → 查台架/供电，**禁止**进闭环 |
| 产出 | 确认 400 Hz「听得懂油门」 |

### V2 — 回答 Q2（map 是否可复用）

| 项 | 内容 |
|----|------|
| 做法 | **同一探点 1100 μs**：先 `FREQ 50` 持 3 s 记 mean；再 `FREQ 400` 持 3 s 记 mean（点间停转） |
| PASS | \|mean_400 − mean_50\| ≤ max(50, 10%×mean_50) |
| MARGINAL | 偏差略大但仍同量级 → 最终实验可继续，但盯稳态误差 |
| FAIL | 偏差很大或 400 不转 → 最终实验前考虑重学或放弃 400 |
| 产出 | **是否允许不重学 map 直接闭环** |

### V3 — 回答 Q3（闭环低点）

| 项 | 内容 |
|----|------|
| 做法 | `FREQ 400` + CLOSED + 现参数；停转→**1000** RPM × 8 s |
| PASS | 入带 ±10%，末段误差&lt;10%，无 ESTOP |
| FAIL | 先查模式/FREQ/死区；**仍不改** Ka/SOFT |
| 产出 | 400 Hz 下「最小工作闭环」成立 |

### V4 — 回答 Q4 前半（中点）

| 项 | 内容 |
|----|------|
| 做法 | 1000→**2000**→**3000**，每点 8 s（`FREQ 400`） |
| PASS | 两点均 PASS；超调&lt;15% |
| 若稳态偏、动态尚可 | 记误差；允许最终实验，但报告标 MARGINAL map |
| 若动态明显抖/冲 | **暂停**最终实验；只允许改 **一项**（略降 Ka 或略降 UP）后重做 V4 |
| 产出 | 中速段是否随转速恶化 |

### V5 — 回答 Q4 后半（高点+顶点）

| 项 | 内容 |
|----|------|
| 做法 | 3000→**4000**→**5000**→**6000**（可拆成 V5a=4k/5k、V5b=6k） |
| PASS | 各点 PASS；脉宽明显低于 2500 μs（无夹断） |
| FAIL | 记失败转速与脉宽；若脉宽顶满 → 供电/map；若脉宽正常仍偏 → PI/测速 |
| 产出 | 全量程在 400 Hz 是否逐步可达 |

### V6 — 回答 Q5（动态，可选）

| 项 | 内容 |
|----|------|
| 做法 | A1：1000→2000；A2：3000→2000（参数仍固定） |
| PASS | 可重复入带；超调不长期&gt;15% |
| 对比 | 与历史 50 Hz S1 同量级即可，**不要求更好** |
| 若 A2 变差 | 记「空载仍靠 DOWN」；**默认仍 ADG OFF** |
| 产出 | 是否需要为 400 Hz 单独动 Ka/ADG（通常否） |

## 3. 最终实验 F（仅当验证门通过）

**准入**：V1–V3 必须 PASS；V4–V5 必须 PASS（或 V5 书面豁免）；V6 建议做完。

**做法（一次做完，作结案数据）**

1. `FREQ 400`，参数固定（或仅含 V4 批准的那一项改动）  
2. 闭环阶梯 **1000→2000→3000→4000→5000→6000**，每点 settle 8 s  
3. （可选）紧接 A1/A2 各一次  
4. 结束：`FREQ 50`，出报告 `空载多点_F400_最终_*.md`

**结案标准**

- F 全 PASS → 工作默认更新为 **FREQ=400**（50=安全回退；600=开环摸底上限）  
- 控制参数：无新证据则 **维持** Ka=0.05、SOFT 800/300、ADG OFF  
- 有 V4/V5 批准的单项改动 → 写入冻结表并说明来自哪次验证

## 6. 与控制方法备忘的关系

- S0–S3 **分层不变**；本文件只验收「载波=400」这一维。  
- 空载减速认知不变：DOWN 斜坡主导 → V6 差也不优先 ADG。  
- Q6（400 vs 600）用周期夹断论证，避免无必要的 600 Hz 闭环冒险。
