## 1. 我们要做什么（一句话）

用 **ESP32-S3** 读 **AS5047P 磁编码器** 得到真实转速，同时向 **航模电调** 输出 **400 Hz、1000~2000 μs** 油门 PWM，通过 PC 界面设定 **0~2000 RPM** 目标转速，先测量再闭环控制；当前空载调试，将来接扑翼机。

## 2. 硬件与边界（已基本确定）

| 项 | 现状 |
|----|------|
| 主控 | ESP32-S3 |
| 角度/转速反馈 | AS5047P（SPI，GPIO10/11/12/13） |
| 电调信号 | GPIO9 → 电调信号线；共地；**不接 BEC 5V 到 ESP32** |
| PWM | 400 Hz；脉宽 **1000 μs（最低）~2000 μs（最高）** |
| 上电安全 | 固件一启动就输出 **1000 μs**，避免误油门 |
| 目标转速范围 | UI 设定 **0~2000 RPM** |
| 负载 | **现在空载**；**将来接扑翼机构** |

**重要边界**：标准航模电调是黑盒，我们**只能改油门脉宽**，不能做 FOC / 电流环。转速闭环只能靠编码器外环。

---

## 3. 我们查到的“电调配对”是什么

向朋友确认前，先说明我们的理解（请纠正）：

航模里常说的「电调校准 / 配对」**不是**把某款电机型号写进电调，而是：

> **油门行程校准**：让电调记住「本控制器」的最高油门与最低油门脉宽。

典型流程（Hobbywing / BLHeli / ArduPilot 一类）：

1. 控制器先输出**最高油门**（约 2000 μs）  
2. **再给电调上电**  
3. 电调鸣叫确认已记录最大值  
4. 再拉到**最低油门**（约 1000 μs）  
5. 长鸣确认最小值 → 行程对齐  

注意：

- 校准前应卸桨 / 固定好，防误转  
- DShot 等数字协议通常不需要这套行程校准；我们用的是**模拟 PWM 脉宽**，一般需要  
- 行程校准之后，才谈得上「脉宽 ↔ 转速」测量与闭环  

**请朋友确认**：我们这套电调品牌/型号是否也是这套流程？有没有特殊要求（如必须先最低油门上电解锁、禁止高油门上电等）？

## 4. 控制思路（我们倾向的方案）

### 4.1 为什么不纯开环、也不一上来神经网络

| 方案 | 我们的判断 |
|------|------------|
| 纯开环油门 | 实现简单，但电压/负载一变转速就漂；扑翼后更不可靠 |
| 纯 PI/PID | 可以，但没有前馈时阶跃慢、易来回追 |
| **前馈油门图 + PI** | **倾向方案**：先测 `脉宽→转速`，控制时用反函数当前馈，PI 修误差 |
| FOC / 状态反馈 | 电调内部才有，我们碰不到 |
| NN 自适应 PID | 文献多，但调试成本高，适合后期 |

### 4.2 分阶段

```text
① 电调行程校准（配对）
② 测量模式：加大脉宽，观察编码器转速，记 (pulse, rpm) 点
③ 保存前馈图 + 根据斜率建议 PID
④ 闭环：目标 RPM → 前馈 + PI
⑤ 将来扑翼：换 profile 重新测量；再考虑自适应 / 增益调度
```

### 4.3 空载 vs 扑翼

- 空载惯量小、几乎无周期气动负载 → 适合先把测量与闭环跑通  
- 扑翼后负载近似**周期变化**（扑动频率及其谐波）→ **空载前馈图不能直接当真**，必须再测一套（计划用 `noload` / `flap` 两个 profile）  

**请朋友确认**：扑翼工况下，你们更关心「平均转速稳」还是「瞬时转速波纹也要小」？这决定后期要不要做谐波抑制。

## 5. 人机界面需求（已定稿方向）

| 功能 | 说明 |
|------|------|
| 转速圆盘 | **按住旋转**设定目标；**转 4 圈 = 2000 RPM**（500 RPM/圈） |

| 电调校准 | 高油门 / 低油门 / 完成 向导 |
| 模式 | 开环 / 闭环 / 测量 / 安全 |
| PID | 可显示、可改、可保存；测量后可出建议值 |

## 9. 成功标准（建议）

短期（空载）：

- [ ] 电调可靠解锁，低油门不转  
- [ ] 测量模式下脉宽增加，编码器 RPM 单调可重复  
- [ ] 保存前馈后，设定 500 / 1000 / 1500 RPM，稳态误差可接受（请朋友帮定：例如 ±5% 或 ±50 RPM）  
- [ ] 急停立即停转  

中期（扑翼）：

- [ ] `flap` profile 重测后可稳定在常用工作转速  
- [ ] 扑动引起的转速波动在可接受范围（数值待定）  
- [ ] 长时间运行无异常发热、无失控
