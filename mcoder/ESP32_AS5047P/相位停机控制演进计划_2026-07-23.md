# 相位停机控制演进计划 · 2026-07-23

> **意图**：按 **先易后难 / 先简后繁** 逐级尝试全部阶段；除非被硬约束或台架阻塞，**不跳过、不幻想**「反转/主动刹」。  
> **原则**：BRAKE/SETTLE **禁止**「位置误差 → 加油门」；策略评价在监督层，执行仍是单向松油 + 滑行。  
> **红旗（必盯）**：若停相误差或所需爬行角 **>90°**（尤指 **~200°**），**不是**普通小 miss——必须按 §3 分流诊断，禁止直接调 `brake_k`/lead 了事。  
> **代码真相源**：`firmware/ESP32ReadAS5047P/ESP32ReadAS5047P.ino`（`holdPhase*`）。

## 0. 硬约束（全程不可破）

| 约束 | 说明 |
|------|------|
| **单向 ESC** | 油门约 1000–2000µs；**无主动制动、无反转**。切油后只保持 1000µs，等 `stop_rpm` / 延时滑行。 |
| **霍尔绝对标记** | GPIO4 → `disc_ref=0°`；GPIO5 → `disc_ref=180°`。 |
| **齿轮** | `gear = 4661/168`（≈27.744）；互质齿 → **每次**有效霍尔沿重锁 `disc_ref` + 当时堆叠电机 counts。 |
| **盘角合成** | `disc = wrap(ref + sense·Δmotor/gear + OFFSET)`；磁编用堆叠 `enc_cb_counts`，禁止首锁永用 / 单圈 raw 直减。 |
| **数值主路** | **浮点**（`FIXED?=0`）；Q16 仅备份，不切生产。 |
| **速率** | 采集/使用 **2k Hz**；控制输出 **400 Hz**；实时路径禁直打串口。 |
| **终端动作** | 目标窗内唯一合法动作是**松油门**；再踩只会冲过。 |

## 3. 分析红旗：停相误差 / 爬行角 >90°（尤指 ~200°）

> **本条为全文分析准则，贯穿 P0–P6 与台架判读。**  
> 首停后若 **爬行剩余角 `crawl_remain > 90°`**，或 wrap 误差 **`|err| > 90°`（可到 ~200°）** → **红旗**，不是「差一点再爬」的正常小 miss。

### 3.1 触发条件（任一即红旗）

| 触发 | 定义 | 严重度 |
|------|------|--------|
| **爬行过大** | 进入 REFINE / 停后补爬时，`remain` 或计划爬行盘角 **>90°** | 高 |
| **首停大误差** | `err = wrap180(disc − target)`，**`|err| > 90°`** | 高 |
| **~200° 族** | `|err| ≈ 150°~210°` 或盘读约 **~180°/~189°/~200°**（历史策略 C miss） | **特高** — 优先当标架/估计，勿当微调 k |

### 3.2 强制三分支分类（禁止混调）

每次红旗必须先归入 **一类主因**，再允许改参数：

```text
                    |err|>90° 或 crawl>90°
                              │
          ┌───────────────────┼───────────────────┐
          ▼                   ▼                   ▼
   A. 估计 / 标架          B. 策略入口           C. 监督失职
   stale latch / wrap      soft-down→RPM0        本应早 REFINE
   / OFFSET≈±180           / timeout / k 盲切    或中止软降却未做
```

| 分支 | 典型证据 | 处置 | **禁止** |
|------|----------|------|----------|
| **A. 估计/标架** | `bias` 稳在 **≳150°**；或重复半圈着陆；霍尔 latch 年龄大、堆叠 counts 跳变 | `PHASE OFFSET ±180`；查每沿 `discLatchHall` + `enc_cb_counts` | 猛调 `brake_k`/lead |
| **B. 策略入口** | 软降后 **RPM≈0**、timeout、从未合法 BRAKE；或小 bias 但切油点乱 | **P0** 修软降/爬行；再谈学 k | 当 OFFSET 乱拧半圈 |
| **C. 监督失职** | remain 仍 **>90°** 且 RPM 已塌；或本可早进 REFINE/abort soft 却拖到超时 | **P1/P5** 规则：stall-risk / 强制早 REFINE / 中止软降 | 仅加长 timeout 糊弄 |

**单次 ~200°（one-shot）**：除分类外，日志栈必须抓：**堆叠 motor counts**、**末次霍尔年龄（last Hall age）**、`disc_ref`、`OFFSET`、`remain`、`rpm`、state。稳定复现再归 A；偶发先排除 B/C。

### 3.3 监督层硬规则（与 §4 合并落地）

| 规则 ID | 条件 | 动作 |
|---------|------|------|
| **R-stall90** | `remain > 90°` **且** RPM 已塌（≈0 / 远低于 crawl） | 标 **stall-risk** → OPEN crawl 救场，或 **中止软降 / 失败退出**；禁止干等 timeout |
| **R-bias150** | 停后 `bias` **≳150°** 且多次稳定 | 判 **OFFSET/标架**；冻结学 k；提示 `PHASE OFFSET` |
| **R-200shot** | 单次着陆 **~200° 族** | 打红旗日志：`counts` + `last_hall_age` + ref/OFFSET；不自动学 k |
| **R-earlyRefine** | 0°/180° 目标，首停 `|err|>90°` 或 crawl 将 >90° | 监督应 **强制早 REFINE**（或 abort soft→REFINE），勿在 APPROACH 空转半圈 |
| **R-crawl120** | `remain` 或 `|err|` **>120°**（长弧补爬/REFINE） | **抬高初始爬行转速**（约 ≥220 RPM 带，非整段 ~50）；**CLOSED 持续油门** 避免开环断续；remain 落到 **≲90° / refine 窗** 再细爬 Hall 捕获 |

### 3.4 路线图验收门闩（各阶段共用）

| 门闩 | 要求 |
|------|------|
| **G-noSilent200** | 出现 `|err|>90°` / crawl>90° / ~200° 时，日志必须带 §3.2 分支标签（A/B/C）+ 必填字段（counts、hall age） |
| **G-noKOnFrame** | 归类为 A（标架）的样本 **不得** 写入 `brake_k` EMA |
| **G-P0** | P0 验收集中 **不得** 出现「RPM0 + remain>90° + timeout」主路径 |
| **G-P1** | 人为/复现 R-stall90 时，监督必须触发（可见标志），不得沉默拖死 |
| **G-P2** | 故意 OFFSET 半圈 → 稳定检出 bias≳150°；标架正确后红旗率下降 |
| **G-passBand** | 标架正确后，常态目标：`|err|≤tol`（朝 ±5°）；**偶发** `|err|∈(tol,90°]` 可 REFINE；**`|err|>90°` 计红旗事件**，计入阶段是否通过 |

### 3.5 台架检查（文档级；本任务不要求上机）

续作上机时可核对（不 flash 亦可先读旧日志）：

1. DONE/ESTOP 行：`err`、`remain`、是否 REFINE、`brake_k` 有无更新。  
2. 若 `|err|>90°`：有无 `bias` / OFFSET 建议；有无 counts + last Hall age。  
3. 软降：SOFTDONE 时 `rpm` 是否仍 ≥ crawl 门闩；有无 RPM0→timeout。  
4. 对照 [相位与磁编换算说明_2026-07-23.md](相位与磁编换算说明_2026-07-23.md) §5。

## 4. 监督状态控制器（架构靶心）

> **不是**在 BRAKE 里做误差→油门；而是 **实时策略评价器**，决定「此刻该用哪条 APPROACH/切油/放弃/REFINE 策略」。  
> **大误差红旗规则见 §3.3**，本表为总览。

```text
传感/估计 ──► 监督层（健康 / 过快 / 失速风险 / 估计可疑 / 策略可疑）
                 │  打分 + 迟滞（P5 加强）
                 ▼
           选用策略包 ──► APPROACH 规划 / 切油 / REFINE / ESTOP
                 │
                 ▼
           执行层仍单向：跟速 / 1000µs / 霍尔爬行
```

| 监督维度（P1 起步） | 典型判据（示意） | 允许动作 |
|--------------------|------------------|----------|
| **health** | 霍尔沿超时、disc NaN、HOST/ESTOP；**last Hall age 过大** | 中止 / 等 latch |
| **too-fast** | `rpm` ≫ crawl 且 remain 小 | 延长斜坡、禁止过早 cut |
| **stall-risk** | 软降后 rpm→0；**或 `remain>90°` 且 RPM 塌（R-stall90）** | OPEN crawl / 中止软降 / 失败退出；**勿干等 timeout** |
| **long-arc-crawl** | `remain`/`|err|` **>120°**（**R-crawl120**） | 抬高爬行转速 + CLOSED 持续；≲90° 再细爬；禁止整段 ~50RPM 断续点头 |
| **est-suspect** | `est_brake` 与 lead 严重背离；**bias≳150° 稳（R-bias150）**；单次 ~200°（R-200shot） | 冻结学 k；OFFSET 提示；打 counts+hall age |
| **strategy-suspect** | 连续 miss；hall_before_plan；**本应早 REFINE 却空转半圈（R-earlyRefine）** | 更保守 cut / **强制早 REFINE** / abort soft |

**P5** 在此基础上加 **mode scores + hysteresis**，避免策略抖动。全程仍 **禁止反向/主动刹幻想**。

```text
   │                │                ├─► P3 制动表+NVS（选做，须试）
   │                │                └─► P4 选圈+capture（必做）
   │                └─► P5 打分+迟滞（选做）──► P6 自适应/预测（选做）
   │
   └── 全程：|err|>90° / crawl>90° / ~200° → §3 红旗三分支（先分类再调参）
```

**纪律**：先易后难、**全部阶段都要尝试**（选做也要留下「试过/阻塞原因」）；禁止用 P6 掩盖 P0；**禁止用调 k 掩盖半圈标架**。
