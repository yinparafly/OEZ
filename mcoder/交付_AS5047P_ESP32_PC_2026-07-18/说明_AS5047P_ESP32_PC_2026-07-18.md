## 3. 供电说明

- 实物模块丝印：**3.3~5V**（板级已处理芯片供电扩展）。
- **对接 ESP32-S3：推荐 VCC → 3.3V**，SPI 电平与 MCU 一致。
- **不要**把模块 VCC 接 5V 后再把 MISO 直接接到 ESP32（5V 逻辑可能超过 IO 耐压）。
- 共地：模块 GND 与 ESP32 GND 必须相连。

## 4. SPI / 寄存器要点（手册已落实到固件）

依据 ams **AS5047P Datasheet [v1-01]**：

| 项目 | 手册规定 | 本固件做法 |
|------|----------|------------|
| SPI 模式 | Mode1：CPOL=0, CPHA=1；MSB first；≤10 MHz | `SPI_MODE1`，时钟 **2 MHz**（杜邦线稳妥） |
| 命令帧 | 16-bit：PARC(偶校验) + R/W + ADDR[13:0] | `buildReadCmd()` |
| 读时序 | 本帧 MISO = **上一命令** 的数据（Figure 15） | 流水线连续发读命令 |
| 角度 | `ANGLECOM` **0x3FFF**：DAEC 补偿角，14-bit | 主采样读此寄存器 |
| 诊断 | `DIAAGC` 0x3FFC：AGC、MAGL/MAGH | 约每 50 次采样插读一次 |
| 帧间隔 | CSn 高 ≥350 ns | CS 间 `delayMicroseconds(1)` |
| 上电 | `t_pon` 后才有有效角（typ 10 ms） | `setup` 中 delay ≥20 ms |

### 命令帧（Figure 13）

```text
bit15     PARC   偶校验（使 PAR + 低15位 中 1 的个数为偶数）
bit14     R/W    1=读, 0=写
bit13:0   ADDR   寄存器地址
```

读 `ANGLECOM` 的命令字为 **0xFFFF**（与常见样本一致）。

### 数据帧（Figure 14）

```text
bit15     PARD   偶校验
bit14     EF     1=上一命令帧出错
bit13:0   DATA   14-bit 角度等
```

角度换算：

```text
deg = raw * 360 / 16384
rad = raw * 2π / 16384
```

## 5. ESP32 固件

### 5.1 目录（本备份内）

```text
firmware/ESP32ReadAS5047P/ESP32ReadAS5047P.ino
```

工作副本同结构，在 `D:\oezcon\mcoder\ESP32_AS5047P\`。

### 5.2 引脚与采样率

| 项 | 值 |
|----|-----|
| CS / SCLK / MISO / MOSI | GPIO **10 / 12 / 13 / 11** |
| 采样周期 | `SAMPLE_MS = 10` → 约 **100 Hz** |
| SPI | Mode1，2 MHz，MSB first |
| 串口 | **115200** |

### 5.3 串口协议格式

上电后先打印注释行，再周期性输出数据行：

```text
# AS5047P Ready (ESP32-S3) per datasheet SPI Mode1
# format: t_ms,raw,deg,rad,rpm,ef,agc,magL,magH
1234,8192,180.000,3.141593,0.00,0,128,0,0
```

| 字段 | 含义 |
|------|------|
| `t_ms` | `millis()` 时间戳 |
| `raw` | 14-bit 角度原始值 0~16383 |
| `deg` / `rad` | 度 / 弧度 |
| `rpm` | 固件侧角度差分滤波转速 |
| `ef` | SPI 错误标志 |
| `agc` | 自动增益（诊断） |
| `magL` / `magH` | 磁场过弱 / 过强 |

`#` 开头行为注释，PC 程序会忽略。

4. 在本机 **正常** PowerShell/cmd 执行，勿依赖 Cursor 沙箱终端。

脚本内 Sketch 指向本目录下的 `firmware\ESP32ReadAS5047P`；若 COM 不是 18，请改 bat 中的 `PORT=`。

工作工程一键脚本：`D:\oezcon\mcoder\ESP32_AS5047P\flash_com18.bat`。

### 6.4 手工 PowerShell（本备份路径）

```powershell
# 确保未设置 ARDUINO_DATA_DIR
Remove-Item Env:ARDUINO_DATA_DIR -ErrorAction SilentlyContinue

$cli = "D:\Program Files\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe"
$cfg = "C:\Users\tt\.arduinoIDE\arduino-cli.yaml"

& $cli compile --fqbn $fqbn $sketch --config-file $cfg
& $cli upload --fqbn $fqbn -p $port $sketch --config-file $cfg
```

| 阶段 | 判据 |
|------|------|
| 编译 | 出现 `Sketch uses …% of program storage space`，无 error |
| 上传 | 出现 `Hash of data verified` |

### 6.6 串口监视注意

- 波特率 **115200**。  
- **勿拉高 DTR/RTS**：Windows 上若一直复位，板子可能卡在 bootloader，看不到固件日志。  
- PC 程序已设置 `dsrdtr=False`、`rtscts=False`，并强制 `dtr/rts = False`。用其它串口助手时同样关闭「DTR/RTS 复位」。

## 9. 常见问题

1. **角度卡在 ~359.9° / raw=16383（全 1）**  
   查 CS、时钟、MOSI/MISO 交叉是否接反、供电是否为 3.3V、偶校验与 Mode1 是否正确。

2. **偶发 EF=1**  
   降低 SPI 时钟、缩短杜邦线、确认 Mode1（不是 Mode0/Mode3）。

3. **MAGL=1（磁场过弱）**  
   磁铁太远/太弱；手册正常工作约 **35~70 mT**。

4. **MAGH=1（磁场过强）**  
   气隙过小，适当加大气隙。

5. **VCC 接 5V 再直连 ESP32**  
   不推荐；请用 3.3V。

6. **编译报 Platform 'esp32:esp32' not found**  
   清除 `ARDUINO_DATA_DIR`，并用 `--config-file` 指向 `arduino-cli.yaml`。

7. **烧录/监视无输出、一直像进下载模式**  
   关闭 DTR/RTS；关闭其它占用 COM 的程序；确认波特率 115200。

8. **FQBN 报 board not found**  
   不要用 `yd_esp32s3_n8r2`；用 `esp32:esp32:esp32s3`。

9. **PC 表盘汉字变方框**  
   确认本机有微软雅黑等字体；程序会尝试从 `C:\Windows\Fonts` 加载。

10. **COM 号变了**  
    以设备管理器为准，改 `flash_com18.bat` 的 `PORT` 与 PC 程序 `DEFAULT_PORT`。
