# 修改日志 — 2026-07-18 磁编 AS5047P / TLE5012B + ESP32-S3

> 说明：本文件记录今日磁编读取与扑翼控制相关交付；编码 UTF-8。

## 一、今日目标（摘要）
1. AS5047P + ESP32-S3 SPI 读电机相位；PC 显示 0–360° / 0–2π；记录 RPM vs 时间；相位钟表。
2. 板供电 3.3–5V，对接 ESP32 用 3.3V。
3. TLE5012B(5012)：独立工程 + AS5047P/5012 兼容测试版。
4. 控制约定：400Hz 环；1600Hz 过采样平滑→400Hz 输出；扑翼上慢下快非对称正弦；霍尔 0°/180°；减速比≈29（待确认）；外端 2 舵机 50Hz；电调 400Hz；均由 ESP32 控制；单 ESP32-S3 负担评估为够用。
