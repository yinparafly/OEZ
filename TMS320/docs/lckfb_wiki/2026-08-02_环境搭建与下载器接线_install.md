## 工程模板搭建 [​](#工程模板搭建)

### 使用图形化配置引脚 [​](#使用图形化配置引脚)

我们通过点亮开发板上的灯来进行验证。首先要修改代码，使其可以控制灯。

在工程目录下，找到以 .syscfg 为结尾后缀的文件，该文件是 TI 旗下的图形化代码生成工具，打开它。

![](/storage/images/zh-hans/tms320f28p550/beginner/install/install_20250310_193846.png)

第一次打开时会要求配置芯片型号，开发板的主控是 TMS320F28P550SJ9PZ，根据选项信息，选择下图参数：

![](/storage/images/zh-hans/tms320f28p550/beginner/install/install_20250310_194103.png)

在打开的图形化代码生成工具中，找到 GPIO 外设，添加一组引脚，配置使用 LED 灯的 GPIO21 引脚。完成后保存。

![](/storage/images/zh-hans/tms320f28p550/beginner/install/install_20250310_194718.png)

找到工程的 empty\_driverlib\_main.c 文件，将整个文件中的内容，更新为以下代码：

代码（点击展开）

c

```
#include "driverlib.h"
#include "device.h"
#include "board.h"
#include "c2000ware_libraries.h"
#include "sysctl.h"

void main(void)
{
    Device_init();

    Device_initGPIO();

    Interrupt_initModule();

    Interrupt_initVectorTable();

    Board_init();

    C2000Ware_libraries_init();

    EINT;
    ERTM;

    while(1)
    {
        GPIO_writePin(myGPIO0, 0);
        DEVICE_DELAY_US(1000000);
        GPIO_writePin(myGPIO0, 1);
        DEVICE_DELAY_US(1000000);
    }
}
```
