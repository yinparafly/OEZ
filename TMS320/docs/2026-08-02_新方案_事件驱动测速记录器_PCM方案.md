# 新方案：事件驱动测速记录器（PCM 逐计数中断）——交流版

> 日期：2026-08-02（v2：主频修正 150MHz + 三朋友答复吸收）
> 背景：原设计假设 eQEP 捕获单元有中断，经头文件/官方例程静态分析确认**不存在**（详见 `2026-08-02_eQEP捕获中断缺失_问题与发现.md`）。
> 本文是当前方案的完整自述，供继续交流与评审。
> 设备：TMS320F28P550SJ9（**150MHz** C28x；EQEP1：A=GPIO50 B=GPIO51 I=GPIO53）。

---

## 1. 目标（不变）

ABI 编码器（1000PPR，4X=4000 计数/圈）**事件驱动非均匀采样**测速记录：
每个计数变化记录 16B 事件点 (t_us, counts, index_n)，还原扑翼/弹射速度轨迹：
**低速不量化、高速不丢总计数**。设计上限 20000rpm（4X 时 1.33M 边沿/s，0.75µs/边沿）。

## 2. 硬件现实（为什么原方案不行）

| 原假设 | 现实 |
|---|---|
| QCAP 捕获中断逐边沿通知 | **无捕获中断**。QCAPCTL 仅 UPPS/CCPS/CEN；QFLG 13 标志无捕获位；官方 ex4/ex5 用 UTO 轮询 |
| 运行时切 1X/4X 降中断率 | 正交模式**恒 4X**；XCR 只对 CLOCK_DIR 模式生效 |
| QCPRD 周期测速 | 16 位，@150MHz 最大 436.9µs，<34.3rpm 溢出 |
| QCTMR 扩展 64 位绝对时钟 | 每捕获清零，不能作绝对时钟 |
| EPG 边沿测量中断 | 只有 SIGGEN0_DONE/FILL |

## 3. 新方案 A：位置比较（PCM）逐计数中断

### 3.1 原理

```
QPOSCMP = QPOSCNT ± N   （N=1 逐计数；N=4 降速档）
PCSHDW=1 + PCLOAD=1      （影子使能；匹配瞬间硬件自动装载影子值，ISR 无竞争）
方向反转 → QDC 中断重新武装（防 QPOSCNT 背离 QPOSCMP 失配）
Index    → IEL 中断（每圈校准 + 圈计数）
三个源同一 INT_EQEP1，ISR 内读 QFLG 分发
```

### 3.2 ISR 流程（INT_Module_EQEP_ISR，已吸收加固建议）

```
读 QFLG → 分发：
PCM:  先读 QPOSCNT + 时间戳（缩小窗口）
      delta = raw − raw_prev（±2³¹ 回绕修正）→ canonical counts += delta
      漏事件计数：|delta| > step 时 g_missed_events++（优雅降级观察）
      t_us = µs 时钟差分 → 周期 → rpm；snap_on_event(now, counts, index_n)
      重新武装 QPOSCMP = raw + dir × step
QDC:  按新方向重新武装
IEL:  index_n++；若校准挂起 → canonical = index_n × 4000
清 QFLG（写完 CMP 后）→ 清 ACK
```

### 3.3 时间戳（不再依赖 QCAP/QCTMR）

- **CPUTIMER0 自由运行**（countdown，周期=SYSCLK/1000=150000 tick）
- **1kHz ISR** 维护：`g_us64`（每 tick +1000）+ `g_us_tick_cnt`（countdown 快照）
- 亚 µs 精度插值：`t_us = g_us64 + ((g_us_tick_cnt − cnt + period) % period)/150`
- u64 撕裂读：hi/lo/hi retry

### 3.4 周期测速

ISR 内相邻事件 µs 差分 → 周期 → rpm。
**不启用 QCAP**（16 位溢出 + 无中断，无收益）。

### 3.5 分档（软件等效降速）

正交模式无法硬件切分辨率 → **PCM 步长 N**：
- GEAR_4X：N=1（逐计数，低速高精度）
- GEAR_1X：N=4（ISR 速率 /4，高速降 CPU 负载）
- canonical 计数恒精确（QPOSCNT 硬件累加，N 只影响 ISR 触发密度）
- 中高速可自动加大 N（按最近速度估计，迟滞防抖）

### 3.6 优雅降级

ISR 追不上时（delta>N）：计数精确（读 QPOSCNT 差值追赶），
中间边沿的精确时间戳丢失 → 记录 `g_missed_events` 供联调评估。

## 4. ISR 开销预算（150MHz，v2 修正事件率）

| 项 | 值 |
|---|---|
| 设计上限 | 20000rpm → 4X 事件率 = 20000×4000/60 = **1.333M 边沿/s**，0.75µs/边沿 ≈ **112.5 周期**（⚠ v2 修正：旧版误写 400kHz/2.5µs/375 周期） |
| ISR 预算 | 0.6µs = **90 周期**（@150MHz），禁浮点/除法（rpm 移到 1kHz） |
| N=1 满速占用 | 0.6/0.75 ≈ **80% CPU** —— 不可持续 → 满速必须 GEAR_1X |
| GEAR_1X（N=4）满速 | 333k 边沿/s → 3.0µs/边沿 → **22% CPU** ✓ |
| 降档策略 | 事件间隔 < ~1.2µs（rpm > ~12500@N=1）即切 GEAR_1X；Task 6 Step 4 实测 >0.6µs 立即降档 |
| 判定 | 100kHz 模拟脉冲实测 ISR 开销（GPIO 翻转示波器 / CPU Timer 差分） |

## 5. 待上板验证事项（Checklist，★=最高优先级）

- [ ] ★ **QPOSMAX→0 回绕瞬间的匹配行为**（CMP 回绕安全，失配则中断停摆）
- [ ] ★ **方向反转瞬间**（QDC 重武装窗口，换向不丢事件）
- [ ] **正交模式 4X 确认**：电驱动多圈、多速度（如 100/500/2000/6000rpm 分段），QPOSCNT 每圈恒 ≈4000（低速手转+电驱动均可用，时间不设限）
- [ ] **PCM N=1 逐计数**：低速电驱动（或手转）每个计数都进 ISR（用漏事件计数验证）
- [ ] 100kHz 模拟脉冲测 ISR 实际开销（CPU Timer 差分 / GPIO 翻转示波器）
- [ ] **时间戳插值公式**：已知频率脉冲校准（countdown 方向 + 跨 1kHz 边界取模）
- [ ] **eQEP 输入 qualifier 用同步模式**（异步模式禁止），确认 SysConfig 配置
- [ ] PCM 匹配延迟 td(PCS-OUT)QEP=7 周期（示波器对比输入沿 vs ISR 响应）
- [ ] 921600 波特率实测偏差（预期 +1.72%：LSPCLK=37.5MHz，BRR=4 → 937500；勿改 LSPCLK 分频）

## 6. 备选方案 B（对比用，暂不实现）

UTO（单位时间超时）1kHz 周期采样：实现最简最稳，但每 tick 只记 1 点、逐边沿事件时间全丢。
Task 12 联调后可选把 eqep_abi.c 换成方案 B 对比事件时间分辨率与 CPU 开销。

## 7. 其他路线（评估结论：均不改变方案 A）

- GPIO XINT：真边沿中断，但无 4X 解码、噪声敏感（★★）
- CLB+XBAR+DMA：每边沿时间戳+计数 DMA 搬运免 CPU（片上小 FPGA），开发成本高（★ 后期优化）
- eCAP：有边沿中断但 1-2 路无法同时处理 A+B 正交（不适合）

## 8. 第三轮评审反馈与吸收（2026-08-02 晚，三位朋友评审 PCM 方案）

### 已修正（硬伤）
1. **事件率计算错误（G）**：20000rpm 4X = 1.333M 边沿/s = 0.75µs/边沿 ≈112.5 周期（旧版误写 400kHz/2.5µs）。
   连锁结论：N=1 满速 80% CPU 占用不可持续 → **满速必须 GEAR_1X（N=4）**，§4 已修正。
2. **ISR 内禁浮点/除法（G）**：rpm 计算移出 ISR（1kHz speed_est 用整数 period 差分算 rpm），
   ISR 只做整数 µs 差分 + 计数累计（90 周期预算内）。
3. **时间戳插值公式（G）**：countdown 方向与跨 1kHz 边界取模需上板用已知频率脉冲校准（Checklist 新增项）。

### 已确认（无需改设计）
4. **eQEP 输入时序（G）**：同步模式最小输入周期 2×tc=13.33ns（≤75MHz），A/B 各 37.5MHz；
   20000rpm 时 A/B 仅 333kHz，硬件无压力。⚠ 输入 qualifier 必须用同步模式。
5. **LSPCLK（G）**：默认 /4 = 37.5MHz（sysctl.h L557 注释 default），BRR=4 → 937500 +1.72% ✓。
   注意若以后改 LSPCLK=/1（150MHz），BRR=20 → 892857（-3.1%）超差，不能改。
6. **1kHz 时钟优先级（G）**：PIE 组 1（INT1.7 TIMER0）天然优先于组 5（INT5.1 EQEP1）——g_us64 不漂移 ✓；
   代价是 EQEP ISR 偶尔被 1kHz 抢占（余量已含在预算中）。
7. **PCM 延迟（dp）**：td(PCS-OUT)QEP = 7 SYSCLK（数据手册 6.16.5.1.2），固定延迟不影响测速（差分），
   只影响绝对时间校准，记录为系统误差即可。
8. **回绕安全（dp）**：QPOSMAX=0xFFFFFFFF 时 `QPOSCMP = raw + dir×step`（32 位截断）天然模 2³² 回绕安全，
   无需额外取模；上板 Checklist 最高优先级验证项。
9. **漏事件合并点（G）**：点结构 16B 协议不变，PC 端用**相邻点 counts 差分 > gear step** 识别合并点，
   绘图特殊处理，避免"平滑假象"。

### 后期优化候选（不阻塞当前开发）
10. **CLA 卸载（dp）**：QPOSCNT 读取/快照/差分迁移到 CLA（150MHz 独立于 CPU），
    CPU 只记录事件点；ISR 预算吃紧时启用（Task 12 后评估）。
11. **Index 校准时机（G）**：canonical=index_n×4000 校准只在低速+稳定时执行（校准挂起标志已有），
    防 Index 相位误差引入周期位置跳变。
