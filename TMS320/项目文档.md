## 1. 项目概述

### 1.1 目标
用立创·天机星 **TMS320F28P550SJ9** 开发板实现**事件触发（非均匀采样）测速记录器**，
真实还原弹射/扑翼过程中的速度轨迹：

- 每个 ABI 边沿是一个速度点（事件点），记录其时刻与计数——低速不量化、高速不丢边沿
- 武装 → 触发 → **回溯 400 事件点 + 再记 2400 事件点**（SNAP_CAP=3400 有余量）
- 记录完成后自动存 SD 卡 + 串口拉取；无记录时 10Hz 串口遥测
- 1kHz 速度估计流（实测+外推），为阶段2 的 400~600Hz 闭环输出预留
- 配套**自建精简 PC 工具**（ESP32 工程一律不动）

### 1.2 信号源与设备转速
- AS5047P 磁编码器 ABI 输出（十进制默认 **1000 PPR**，低速自检校准 steps）
- **弹射电机：0–6000 RPM**（低速区要求分辨率/输出频率足够）
- **扑翼机：0–12000 RPM，正常工作 2000–12000**（高速区要求速度真实）
- 3.3V 信号直连，接线用短跳线，信号源靠近处预留 100pF 焊盘（硬件滤波备选）

## 3. 系统设计

### 3.1 架构：事件驱动测速
```
AB 边沿 ──► EQEP1 硬件计数(档位可切) + 捕获锁存
              │  QCPRD/QCTMR 硬件锁存边沿间隔/时刻（CPU 无需逐边沿处理）
              │
              ├─ 记录模式：捕获中断 → 极小 ISR 写 1 点 (t_us, counts, index_n) → 环缓冲
              │              （点时刻=真实边沿时刻，非均匀 ✓）
              └─ 实时模式：1kHz 定时器读最新捕获 → 实测/外推 → 10Hz 串口遥测
                              └──(阶段2) 400~600Hz 固定频率闭环输出
```
- ISR 只做：读 QCPRD/QPOSCNT/QCTMR + 写 16B 点 + 指针自增（无浮点/printf），
  估计 0.3–0.5µs @200MHz。**实际目标上限 12000 RPM（扑翼）→ 最高事件率
  400kHz（G2 档）；G3 为架构预留可能用不到**。>0.6µs 立即启用 2X 降级开关；
  **强制检查点：Task 6 完成后立即实测 ISR 周期数，不拖到联调**（评审 G）。
- **不用高频轮询替代记录中断**：QCPRD 只锁存*最近一个*边沿，轮询率必须高于
  事件率才不丢点，400kHz 事件率下不可行；实时遥测才用 1kHz 轮询读锁存。

### 3.2 分档测速（3 硬件档，设备驱动）
| 档 | 语义（用户 4 阶段） | 解码器 | 捕获边沿 | 事件/圈 | 位置/圈 | canonical | 上切 | 下切 |
|---|---|---|---|---|---|---|---|---|
| G1 | 低速段 ABI 4 倍频 | 4X | A+B 全部 4 沿 | 4000 | 4000 | ×1 | >6500 | <5500 |
| G2 | 中速段非 4 倍频 = 高速段 A 双沿 | 2X | 仅 A 上升+下降沿 | 2000 | 2000 | ×2 | >13000 | <11000 |
| G3 | 速度最大段 A 仅上升 | 1X | 仅 A 上升沿 | 1000 | 1000 | ×4 | — | <26000 |

- **弹射 0–6000 RPM 全程 G1**；**扑翼 2000–12000 跨越 G1+G2**（G2@12000=400kHz）；
  G3 为 >13000 预留（@26000=433kHz）；各档事件率上限 ≈433kHz，ISR 负荷均衡。
- **档位覆盖核算（澄清误读）**：扑翼 2000–12000 轨迹 = G1（2000–6500，4X
  事件率 133–433kHz）→ G2（6500–12000，2X 事件率 217–400kHz）；**G1→G2 上切
  6500（弹射上限附近）、回切 5500**，G2 在正常区真实生效；G2→G3 上切 13000、
  回切 11000。
- **档位合并说明**："A 双沿+位置 1X"与 G2 事件率相同、不省 CPU、只牺牲位置粒度
  （位置不影响测速），故并入 G2；如需独立档，加一行表项即可。
- 切换在 1kHz 主循环（非 ISR）；切换后下一个 I 脉冲把 canonical counts 对齐到
  `index_n*4000`（绝对重校准）。

### 3.3 canonical 计数基准（关键简化）
BIN 内 counts **恒为 4X 基准**（4000 步/圈）：G2 档每事件 +2、G3 档每事件 +4。
→ steps=4000 恒定、无换算舍入、无位置漂移、PC 端无分档处理。

### 3.4 记录流程
```
空闲/遥测 ──MONITOR START──► 武装：环缓冲(1200 点)持续记事件点
  │                              │ |RPM|>10 进 STAGING
  │                              │ 确认：I+1圈 OR ≥200ms OR ring≥120 OR (rpm跌且ring≥40)
  │                              ▼
  │                          回溯环缓冲末 400 点 → 主缓冲（t_us 归一化）
  │                              ▼
  │                          RECORD：续记至 SNAP_CAP=3400（或 REC MS 超时）
  │                              │ 满 → # SNAP DONE → ALIVE(2×1s) → # SNAP DUMP READY
  │                              ▼
  │                     自动写 SD /snap_*.bin → PC 自动 DUMP BIN（SRC=RAM）
  └────────────────────────────────┘
```
- 记录期间**串口静默**（遥测静音，通道干净）；完成后恢复 10Hz。
- **t_us 定义（统一表述）**：t_us = 事件时刻 − 回溯起点（主缓冲首点）时刻；
  首点 t_us=0、单调递增、跨文件可比（各文件以自身回溯起点为零点）。触发确认
  在回溯起点之后约 400 事件处；环缓冲点存相对时刻，回溯时整体平移对齐。
- "rpm跌"定义（评审 G 要求明确数值）：|rpm| < 5（触发门限 10 的一半，与
  ESP32 一致），用于 OR 条件 `(rpm跌且ring≥40)`，防低速抖动误/漏触发。

### 3.5 融合过渡 = 双算法交叉验证（用户要求）
- 切换防抖：**迟滞区间 + canonical 连续 + I 重校准**（见 §3.2/§3.3）。
- **交叉验证**：BIN 点内含 t_us 与 counts，PC 端同时画两条 RPM 曲线——
  ① QCPRD 间隔测速（t_us 差分）② counts 差分测速；固件在档位切换处输出
  `# GEAR G<n> n=<snap点号>` 标记（记录期间缓冲；**串口传输时紧跟在 BIN 帧
  CRC 字节之后作为独立文本行输出，PC 收完帧后继续读一行文本即得切换点**，
  不破坏 BIN 帧结构），
  PC 在图上标注切换点，对比两曲线无毛刺。
- 弹射/扑翼场景各 ≥3 次实验无毛刺无跳变 → 此顾虑结案（记录于联调文档）。

### 3.6 速度估计与外推（阶段1 实现，供阶段2 闭环）
- 1kHz 定时器：1ms 内有新事件 → 输出实测速度（QCPRD 换算，档位相关 steps）；
  无新事件 → 前 2 点线性外推（斜率法），钳制 ≥0、≤最大物理转速；
  **最近事件间隔 >100ms → 直接归 0**（不强行外推）。
- 阶段2 再加 3~5 点最小二乘拟合外推（本阶段不实现）。

## 4. 关键设计决策记录（含评审吸收）

| # | 决策 | 理由 |
|---|---|---|
| D1 | 事件触发记录替代 2kHz 固定采样 | 弹射过程事件在时间轴非均匀；固定采样高速夹带边沿、低速量化 |
| D2 | 记录用捕获中断、遥测用 1kHz 轮询 | 事件率需逐边沿，轮询会丢点；遥测只读锁存即可 |
| D3 | 3 硬件档 + 设备驱动分界（6500/13000） | 弹射全程 4X、扑翼跨 4X+2X、事件率上限恒定 ~433kHz |
| D4 | canonical 4000 基准，steps=4000 恒定 | 消除档位换算舍入/漂移，PC 无分档处理 |
| D5 | 触发语义照搬 ESP32 v40 | 成熟验证过的触发条件（OR 组合，非简单与） |
| D6 | 协议与 ESP32 v40 对齐但 PC 端自建 | 二进制格式可互用；ESP32 工程（固件/abi_monitor.py/curve_studio.py）**零修改** |
| D7 | 环缓冲 1200 / SNAP_CAP 3400 | 4X 满速覆盖 ~4.8ms 回溯余量（G 评审）；总内存 ~96.6KB 需 L1/L2 |
| D8 | 外推停止阈值 100ms 直接归 0 | 防低速抖动误报（dp 评审）；拟合外推留阶段2 |
| D9 | 融合过渡 = 迟滞+canonical+双算法交叉验证 | 用户明确：避免跳变毛刺，反复实验对比两算法数据，无毛刺即结案 |
| D10 | 分档切换后 I 脉冲绝对重校准 | 消除任何累积位置误差（dp 建议） |
| D11 | 内存显式段 + .map 核对 + packed 验证 | 大缓冲必须验证实际落位（G 评审） |
| D12 | t_us 零基准 = 回溯起点首点时刻（非触发时刻）；rpm跌=|rpm|<5 | 消除实现歧义（G/dp 二轮评审） |

**评审意见采纳**：ISR 负载实测+2X 兜底、环缓冲加大、写卡重试+错误码、SPIB 引脚
尽早锁定、写卡 LED 状态、串口超时处理、极限场景测试、100pF 信号完整性、
t_us 全局零基准、hz=0 的 mode=event 兼容。
**二轮评审（G/dp，均有条件通过）修正**：ISR 实测提前至 Task 6 强制检查点；
档位覆盖核算澄清（G2 在正常区真实生效，非形同虚设）；t_us 定义统一为回溯起点；
`# GEAR` 串口传输位置明确；.map 不足立即兜底的硬性规则；SD 候选引脚提前给出；
PC 拉帧超时机制；波特率环回测量法；`_Static_assert`；20 字段数澄清；
档位收益评估提前到联调（从 backlog 移出）。
**评审未采纳**：100kHz 轮询替代记录中断（QCPRD 只锁存最近一个边沿，不可行，见 §3.1）。

## 5. 串口协议（PC 端自建，921600 8N1）

### 5.1 指令（与 ESP32 v40 对齐的子集）
`MONITOR START|STOP|ON|OFF`、`REC MS <ms>`（500-3000）、`SNAP?`、`SNAP STATUS`、
`DUMP BIN`、`HEX DUMP`、`FW?`、`TIME <unix_ms>`（ASCII 十进制毫秒）、`PING`、
`HELP`、`ABI?`、`SD INIT/TEST/LIST/DUMP <file>`。

### 5.2 遥测行（10Hz，非记录时）
`L,t_ms,rpm,dir,armed,log_n,drop,hz,counts,seg,phase,pool_n,revs,remain,segs,
revs_total,revs_abs,index_n,index_signed,t_rel,unix_ms`（L 前缀之后 20 字段，
与 ESP32 对齐；dp 质疑 21 个为计数误读——rpm 的符号/小数部分同属 rpm 字段）。

### 5.3 BIN 帧（v2，与 ESP32 二进制格式一致）
```
AA×10 + 55                (11B preamble)
0xAB1C0002                (4B magic LE)
n                         (2B 点数 LE)
hz=0                      (2B LE；事件模式无固定采样率，PC 仅显示用)
点阵 n×16B                (t_us u32, counts i64, index_n u32, LE)
CRC32(payload)            (4B LE；逐位 CRC-32，poly 0xEDB88320, init 0xFFFFFFFF, final ~)
```

### 5.4 标记行
`# MONITOR armed` / `# SNAP DONE n=` / `# ALIVE n=`（2 拍间隔 1s）/
`# SNAP DUMP READY n=` / `# SD SAVE OK|ERR` / `# GEAR G<n> n=<snap点号>` /
`# BIN END n= hz= steps=4000 mode=event bytes= crc=0x...`

## 6. 内存与链接

| 段 | 大小 | 放置 |
|---|---|---|
| SNAP 主缓冲 3400×16B | 54.4 KB | SNAP_RAM 显式段（L1/L2 SARAM，Task 3 验证地址） |
| RING 环缓冲 1200×16B | 19.2 KB | 同上第二段 |
| 代码 + 常量 + bss + 栈 | ~20 KB | RAMLS0-7 + RAMM0/M1 |
| FatFS 工作区 + 扇区缓冲 | ~3 KB | bss |

- 点结构 `#pragma pack(push,1)` 后验证 `sizeof==16`：优先 `_Static_assert`
  （TI C2000 22.6 支持 C11，dp 建议），不可用则 `char[sizeof==16?1:-1]` 数组法。
- **兜底**（L1/L2 不可用）：SNAP_CAP=2800、RING_CAP=800，FatFS 工作区压缩。
- **硬性规则**（评审 G 要求）：Task 3 构建后若 .map 显示 SNAP_RAM 不足，立即
  启用兜底（2800/800），不得带病进入联调。

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| 4X 满速 433kHz ISR 压力 | ISR 极致精简（无浮点/printf）；实测执行时间；2X 降级开关兜底 |
| 档位切换 counts 跳变/毛刺 | canonical 无换算；I 绝对重校准；双算法交叉验证（§3.5） |
| L1/L2 内存不足或不可用 | 显式段 + .map 核对；兜底缩容 2800/800 |
| 921600 波特率误差 | 1KB 环回法实测（§10 项 11）；>±2% 全局降 460800 |
| 写 SD 失败 | 重试 ≤3 + `# SD ERR <code>`；数据仍在 RAM 可 DUMP |
| 高速 AB 信号完整性 | 短跳线 + 预留 100pF 焊盘硬件滤波 |
| FatFS 移植 | R0.15 纯 C，仅 diskio 适配层自写；LFN=1/UNICODE=0（无 ffunicode） |
